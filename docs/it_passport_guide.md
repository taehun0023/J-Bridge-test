# IT パスポート試験 ガイド

## 試験概要

**IT パスポート試験（iパス）** は、IPA（独立行政法人 情報処理推進機構）が実施する **国家試験** です。
ITに関する基礎的な知識を証明する、情報処理技術者試験の中で最も入門的な試験です。

| 項目 | 内容 |
|---|---|
| 試験時間 | 120分 |
| 出題数 | 100問（小問形式） |
| 合格基準 | 総合 600点/1000点 + 各分野 300点/1000点以上 |
| 出題形式 | 四肢択一式（CBT方式） |
| 受験料 | 7,500円（税込） |
| 実施 | 通年実施（CBT） |

## 3分野構成

### 1. ストラテジ系（経営全般）— 約35%

企業活動や法務、経営戦略、システム戦略に関する分野。

| 中分類 | 主要用語 | J-Bridge カテゴリ |
|---|---|---|
| 企業と法務 | コンプライアンス, 知的財産権, 個人情報保護法, 著作権, NDA | `business` |
| 経営戦略 | SWOT分析, ROI, M&A, CSR, ESG, DX | `business` |
| システム戦略 | RFP, SaaS/PaaS/IaaS, ERP, CRM, SCM | `business` |

### 2. マネジメント系（IT管理）— 約20%

システム開発やプロジェクトマネジメント、サービスマネジメントに関する分野。

| 中分類 | 主要用語 | J-Bridge カテゴリ |
|---|---|---|
| 開発技術 | V字モデル, アジャイル, ウォーターフォール | `testing` / `project_management` |
| プロジェクトマネジメント | PMBOK, クリティカルパス, EVM, WBS | `project_management` |
| サービスマネジメント | ITIL, SLA, BCP, インシデント管理 | `project_management` |

### 3. テクノロジ系（IT技術）— 約45%

コンピュータの基礎理論、ネットワーク、データベース、セキュリティに関する分野。

| 中分類 | 主要用語 | J-Bridge カテゴリ |
|---|---|---|
| 基礎理論 | アルゴリズム, 2進数, 論理演算 | `development` |
| コンピュータ構成 | CPU, RAM, ROM, SSD, GPU | `infrastructure` |
| ネットワーク | TCP/IP, LAN, WAN, HTTP, DNS | `infrastructure` |
| データベース | SQL, 正規化, 主キー, トランザクション | `development` |
| セキュリティ | 暗号化, マルウェア, ファイアウォール, 二要素認証 | `infrastructure` |

## J-Bridge IT Glossary カテゴリとの対応

IT パスポート試験の用語は、J-Bridge の既存 6 カテゴリに自然に統合されています。

| J-Bridge カテゴリ | IT パスポート対応分野 |
|---|---|
| `development` | DB基礎、プログラミング基礎、アルゴリズム |
| `testing` | テスト技法、品質管理、V字モデル |
| `design_doc` | UML、設計手法、要件定義 |
| `infrastructure` | セキュリティ、ネットワーク、ハードウェア |
| `project_management` | PMBOK、ITIL、サービスマネジメント |
| `business` | 経営戦略、法務、システム戦略 |

## 파견 엔지니어를 위한 우선 학습 영역

일본 IT 현장 파견을 준비하는 엔지니어에게 특히 중요한 영역:

### 최우선 (업무 즉시 활용)
1. **セキュリティ**: 情報セキュリティ, 暗号化, 認証 — 일본 기업의 보안 의식이 높음
2. **プロジェクトマネジメント**: 報連相, WBS, 進捗管理 — 일본 업무 문화의 핵심
3. **データベース基礎**: SQL, 正規化, テーブル設計 — 실무 필수 지식

### 우선 (면접/업무에 도움)
4. **ネットワーク基礎**: TCP/IP, HTTP, DNS — 인프라 이해에 필수
5. **法務・コンプライアンス**: 個人情報保護法, NDA — 파견 계약 시 필요
6. **経営戦略用語**: DX, ROI, KPI — 비즈니스 회화에 자주 등장

### 참고 (배경 지식)
7. **ハードウェア**: CPU, メモリ, ストレージ — 기본 IT 상식
8. **IT戦略**: ERP, CRM, SCM — 기업 시스템 이해

## 저작권 참고

- IT パスポート試験の **過去問題** は IPA が公開していますが、無断転載は禁止されています
- J-Bridge では試験問題そのものは使用せず、**シラバス（出題範囲）の用語** を参照して学習コンテンツを作成しています
- 用語の説明や例文はオリジナルで作成されたものです
