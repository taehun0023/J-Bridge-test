## 1. 로그인

**페이지:** `/login`

![로그인 화면](images/mentee/01_login.png)

1. 관리자로부터 전달받은 **이메일**과 **비밀번호**를 입력합니다
2. 「ログイン」 버튼을 클릭합니다
3. 최초 로그인 시 온보딩 화면으로 이동합니다

> **참고:** 계정은 관리자가 생성하여 전달합니다. 자체 회원가입은 지원하지 않습니다.

## 2. 온보딩 (초기 설정)

**페이지:** `/onboarding`

> *이 화면은 최초 로그인 시에만 표시됩니다.*

1. **일본인 여부**를 선택합니다
   - 「はい」 선택 시 → 3개 시험 (CS지식, 개발실무, 비즈니스리테라시)
   - 「いいえ」 선택 시 → 5개 시험 (위 3개 + 생활일본어, 비즈니스일본어)
2. **주요 프로그래밍 언어**를 선택합니다
3. 「次へ」를 클릭하여 초기 평가를 시작합니다
4. 각 카테고리별 초기 평가 문제를 풀어 현재 실력을 측정합니다
5. 완료 후 결과 화면에서 5축 레이더 차트를 확인합니다

## 4. 종합시험 게이트

**페이지:** `/dashboard` (시험 사이클 활성화 시)

> *이 화면은 시험 사이클이 활성화되었을 때만 표시됩니다.*

시험 사이클이 시작되면 대시보드가 시험 게이트 화면으로 전환됩니다.

1. 응시해야 할 **시험 목록**이 카테고리별로 표시됩니다
2. 응시할 시험의 「試験を開始」 버튼을 클릭합니다
3. 모든 카테고리의 시험을 완료하면 사이클이 종료되고 대시보드로 복귀합니다

> **참고:** 시험 진행 중에는 대시보드 대신 이 화면만 표시됩니다.

## 5. 종합시험 응시

**페이지:** `/exam/[examId]`

> *이 화면은 시험 응시 중에만 표시됩니다.*

1. 화면 상단의 **타이머**에서 남은 시간을 확인합니다
2. 각 문제의 보기 중 하나를 선택합니다
3. 청해(聴解) 문제의 경우:
   - 재생 버튼을 눌러 음성을 듣습니다 (1회 재생)
   - 속도 조절 가능 (0.75x / 1.0x / 1.25x)
4. 모든 문제를 풀었으면 「提出」 버튼을 클릭합니다
5. 시간 초과 시 자동으로 제출됩니다
6. 제출 후 점수와 합격/불합격 결과가 표시됩니다

## 6. 생활일본어 학습

**페이지:** `/japanese/jlpt`

![JLPT 학습 메인](images/mentee/06_jlpt_main.png)

생활일본어(JLPT) 메인 페이지에서 5개 카테고리를 학습할 수 있습니다:

| 카테고리 | 페이지 | 내용 |
|----------|--------|------|
| **語彙 (어휘)** | `/japanese/jlpt/vocabulary` | N5~N1 레벨별 단어 목록, 예문 |
| **文法 (문법)** | `/japanese/jlpt/grammar` | 문법 패턴, 예문, 해설 |
| **読解 (독해)** | `/japanese/jlpt/reading` | 독해 지문, 해석 연습 |
| **聴解 (청해)** | `/japanese/jlpt/listening` | 청해 스크립트, TTS 음성 재생 |
| **漢字 (한자)** | `/japanese/jlpt/kanji` | 한자 읽기/쓰기 학습 |

![JLPT 학습 상세](images/mentee/06_jlpt_detail.png)

1. 원하는 카테고리를 클릭합니다
2. 레벨(N5~N1)을 선택하여 학습 콘텐츠를 확인합니다
3. 청해 항목에서는 재생 버튼으로 음성을 들을 수 있습니다

## 9. 비즈니스일본어 이해도테스트

**페이지:** `/japanese/business/quiz/tests?type=...`

각 학습 페이지(용어집/문형/표현/경어)에서 80% 이상 학습을 완료하면 「理解度テスト」 버튼이 활성화됩니다.

1. 학습 페이지 하단의 「理解度テスト」 버튼을 클릭합니다
2. 해당 카테고리의 풀 퀴즈가 표시됩니다 (랜덤 출제, 난이도별 배분)
3. 문제를 풀고 제출합니다
4. 결과를 확인합니다

> **참고:** `/japanese/business/quiz`에 직접 접근하면 비즈니스일본어 메인 페이지로 이동합니다.

## 14. Java 자격증 코스

**페이지:** `/dev/java?tab=cert`

![Java 자격증](images/mentee/14_java_cert.png)

> Java 카테고리에서만 「資格証」 탭이 제공됩니다.

1. `/dev/java` 페이지에서 「資格証」 탭을 클릭합니다
2. 3단계 코스가 표시됩니다:
   - **ブロンズ (브론즈)** — 기초
   - **シルバー (실버)** — 중급 (브론즈 완료 시 해금)
   - **ゴールド (골드)** — 상급 (실버 완료 시 해금)
3. 해금된 코스의 레슨을 클릭하여 학습합니다

## 19. 학습과제

**페이지:** `/dashboard/assignments`

![학습과제 화면](images/mentee/19_assignments.png)

1. 관리자/멘토가 배정한 학습과제 목록이 표시됩니다
2. 과제 상태를 확인합니다:
   - **未着手 (미착수)** — 아직 시작하지 않은 과제
   - **進行中 (진행 중)** — 진행 중인 과제
   - **完了 (완료)** — 완료된 과제
   - **期限切れ (기한 초과)** — 기한이 지난 과제
3. 과제를 클릭하여 상세 내용을 확인하고 진행합니다
