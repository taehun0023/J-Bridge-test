## 1. 시스템 대시보드

**페이지:** `/admin`

![시스템 대시보드](images/admin/01_admin_dashboard.png)

관리자 대시보드에서 시스템 전체 현황을 한눈에 확인할 수 있습니다:

| 영역 | 설명 |
|------|------|
| **スタットカード** | 총 유저 수, 활성 시험 사이클, 미읽은 알림 |
| **ユーザー統計** | 역할별(admin/mentor/mentee) 유저 분포 차트 |
| **週間アクティビティ** | 최근 4주간 퀴즈/코드 제출 추이 차트 |
| **コンテンツ概要** | 코스, 퀴즈 문제, 용어집 항목 수 |
| **メンター負荷** | 멘토별 담당 멘티 수 차트 |
| **最近の監査ログ** | 최근 시스템 변경 이력 10건 |

1. 관리 대시보드에서 「ダッシュボード」를 클릭합니다
2. 각 영역의 수치와 차트를 확인합니다

## 2. 계정 생성 / 관리

**페이지:** `/admin/users`

![유저 관리](images/admin/02_users.png)

### 신규 계정 생성

1. 관리 대시보드에서 「ユーザー管理」를 클릭합니다
2. 「新規作成」 버튼을 클릭합니다

3. 이메일, 이름, 역할(admin/mentor/mentee)을 입력합니다
4. 「作成」을 클릭합니다
5. 생성된 계정 정보를 해당 사원에게 전달합니다

### 역할 변경

1. 유저 목록에서 대상 유저를 찾습니다
2. 역할 드롭다운에서 변경할 역할을 선택합니다
3. 변경이 즉시 반영됩니다

## 3. 멘토 배정

**페이지:** `/admin/mentors`

![멘토 관리](images/admin/03_mentors.png)

### 멘토 전문분야 설정

1. 관리 대시보드에서 「メンター一覧」을 클릭합니다
2. 멘토의 전문분야를 설정합니다:
   - **일본어 멘토 (jp)** — 일본어 콘텐츠 관리 권한
   - **기술 멘토 (tech)** — 기술 콘텐츠(퀴즈, 코스) 관리 권한
   - **미설정 (null)** — 양쪽 모두 접근 가능

### 멘토-멘티 매칭

1. 멘토를 선택합니다
2. 담당할 멘티를 지정합니다
3. 「保存」을 클릭합니다

## 4. 콘텐츠 관리

**페이지:** `/admin/courses`

![콘텐츠 관리](images/admin/04_courses.png)

### 화면 구성

1. **Step 선택** — 5축(생활일본어/비즈니스일본어/CS지식/개발실무/비즈니스리테라시) 중 선택
2. **섹션 선택** — 「종합시험」 또는 「이해도テスト」
3. **필터** — 난이도, 카테고리, 공개 상태, 클레임 유무
4. **문제 목록** — 문제 텍스트, 카테고리, 난이도, 공개 상태, 클레임 수

### 문제 추가

1. 「+ 問題追加」 버튼을 클릭합니다
2. 문제 텍스트를 입력합니다
3. 난이도와 카테고리를 선택합니다
4. 보기 4개를 입력하고 정답을 라디오 버튼으로 선택합니다
5. (선택) 해설을 입력합니다
6. 「保存」을 클릭합니다

### 문제 수정

1. 문제 행의 「編集」 버튼을 클릭합니다
2. 내용을 수정합니다
3. 「保存」을 클릭합니다

> **주의:** 진행 중인 종합시험에 포함된 문제는 수정/삭제할 수 없습니다.
> 시험 완료 후 수정해 주세요.

### 문제 공개/비공개

1. 문제 행의 공개 상태 토글을 클릭합니다
2. 비공개 문제는 퀴즈와 시험에 출제되지 않습니다

### 클레임 처리

멘티가 문제에 오류를 신고하면 클레임으로 접수됩니다.

1. 빨간 클레임 배지가 있는 문제를 클릭합니다
2. 클레임 내용(사유, 신고자, 일시)을 확인합니다
3. 문제를 수정하면 클레임이 **자동 해결**됩니다
4. 수정 없이 해결하려면 「全件解決」을 클릭합니다
5. 여러 문제의 클레임을 한번에 해결하려면 툴바의 「クレーム一括解決」 버튼을 사용합니다

## 5. 과제 배정

**페이지:** `/admin/tasks`

![과제 배정](images/admin/05_tasks.png)

### 학습과제 생성

1. 관리 대시보드에서 「タスク管理」를 클릭합니다
2. 「新規課題」 버튼을 클릭합니다
3. 대상 멘티, 과제 내용, 기한을 입력합니다
4. 「作成」을 클릭합니다

### 재시험 요청 처리

1. 「再試験リクエスト」 탭을 선택합니다
2. 요청 목록에서 멘티와 시험 카테고리를 확인합니다
3. 「承認」 또는 「却下」를 클릭합니다

### 과제 상태 관리

과제의 상태 흐름:

```
未着手 (pending) → 進行中 (in_progress) → 完了 (completed)
                                        → 期限切れ (overdue)
```

## 6. 성적 리포트

**페이지:** `/admin/reports`

![성적 리포트](images/admin/06_reports.png)

1. 관리 대시보드에서 「レポート」를 클릭합니다
2. 조회할 사원을 선택합니다 (관리자는 전체 사원 조회 가능)
3. **시험 사이클별 점수 추이** 그래프를 확인합니다
4. **카테고리별 오답률** 차트를 확인합니다:
   - 빨강 (50% 이상) — 즉시 보강 필요
   - 노랑 (30~50%) — 주의 필요
   - 초록 (30% 미만) — 양호

### AI 지도방법 프롬프트

5. 하단의 「AIプロンプトをコピー」 버튼을 클릭합니다
6. 해당 사원의 성적 데이터가 AI 분석용 프롬프트로 클립보드에 복사됩니다
7. ChatGPT 등 AI 채팅에 붙여넣으면 약점 분석과 지도 방법을 제안받을 수 있습니다

## 7. TTS 캐시 관리

**페이지:** `/admin/tts-cache`

![TTS 캐시](images/admin/08_tts_cache.png)

청해(聴解) 문제에 사용되는 TTS 음성 캐시를 관리합니다.

1. 관리 대시보드에서 「TTS管理」를 클릭합니다
2. 캐시 상태(생성 수, 용량)를 확인합니다
3. 「一括生成」으로 미리 음성 캐시를 생성할 수 있습니다

> **참고:** TTS 캐시를 사전 생성하면 멘티가 청해 문제를 풀 때 대기 시간이 줄어듭니다.

## 8. 감사 로그

**페이지:** `/admin/audit-log`

![감사 로그](images/admin/09_audit_log.png)

시스템에서 발생한 모든 변경 작업을 추적할 수 있습니다.

1. 관리 대시보드에서 「監査ログ」를 클릭합니다
2. 리소스 타입별 필터로 원하는 항목을 조회합니다:
   - `quiz_questions` — 퀴즈 문제 변경
   - `profiles` — 유저 정보 변경
   - `task_assignments` — 과제 배정
   - `admin_feedbacks` — 피드백 작성
   - `quiz_attempts` — 재시험 처리
   - `learning_assignments` — 학습과제
3. 각 로그에서 변경자, 변경 일시, 변경 내용(before/after)을 확인합니다

## 9. 백업

**페이지:** `/admin/backup`

![백업](images/admin/10_backup.png)

7개 주요 테이블의 데이터를 CSV로 백업할 수 있습니다.

| 테이블 | 내용 |
|--------|------|
| profiles | 유저 프로필 |
| shared_vocab | 공유 단어장 |
| quiz_questions | 퀴즈 문제 |
| learning_assignments | 학습 과제 |
| task_assignments | 과제 배정 |
| admin_feedbacks | 관리자 피드백 |

1. 관리 대시보드에서 「バックアップ」를 클릭합니다
2. 백업할 테이블을 선택합니다
3. 「ダウンロード」를 클릭하면 CSV 파일이 다운로드됩니다
