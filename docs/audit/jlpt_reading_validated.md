### 3-3. 리라이트 전략 권고: **일본어 통일**

**권장**: 한국어 선택지 → 일본어로 모두 재작성.

**근거**:
1. **학습목표**: 이 플랫폼은 "한국인 → 일본 파견" LMS. 독해 영역에서 **목표언어(일본어) 출력 능력**을 평가해야 함. 한국어 선택지는 "번역 이해"로만 검증 → 일본어 문장 처리능력 측정 실패.
2. **A3/B6 충돌**: 한국어로 번역하는 과정에서 "본번 환경 배포"·"본선 환경 배포" 등 모호 용어 다수 발생. 일본어 원문 기반 선택지가 더 정확한 단일정답을 보장.
3. **본문-선택지 언어 일치**: 일본어 본문 / 한국어 선택지 혼용은 인지부하만 높이고 독해 평가로는 부적합.
4. **동일 quiz 내 다른 문제들(Q-0edfc708 上級 B8 only)은 길이는 균등** → 언어 변경만으로 B5·B8 동시 해결 가능 케이스도 다수.

**대안 (기각)**: "한국어 유지(bilingual)" — 초급 학습자 편의를 고려할 수 있으나, 이미 본문이 일본어이고 JLPT/종합시험 체계상 목표어 일관성이 더 중요함. 해설(explanation)에 한국어 주석 추가로 대체 권장.

**Fixer 작업 지시**: 48건 모두 선택지 4개 × 4개 문항 = **192 옵션 텍스트 일본어 번역 UPDATE**. 병행하여 B5 길이 균등화(±20% 이내) 함께 처리.
