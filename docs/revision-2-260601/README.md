## 決定事項 (全項目 確定済)

`decisions.csv` の 21項目はすべて **2026-06-01 に taehun0023 が推奨案で確定**。
個別の見直しが必要になった場合は該当行を上書きしてバージョン管理に残す。

主要決定:
- 「毎週」= 月曜 00:00 〜 日曜 23:59
- 遅延 = `due_date < now() AND status != completed`
- 試験列 = 最新点数 + 合否バッジ (例: `82 ✓`)
- 同一/高難易度再受験 = **最高採用** (最新ではない)
- ヘッダー = 漢字名のみ / 画面本体 = 漢字名 + カタカナ名
- IT 関連資格 = 事前定義ドロップダウン + その他自由記述
- テストアカウント識別 = email `@jbridge.test` または `@test.com`

## Excel での使い方

1. `test-cases.csv` を **Excel でダブルクリック** (UTF-8 BOM 付きなので日本語も正しく表示)
2. テスト実施時に以下を埋める
   - **結果** 列: `PASS` / `FAIL` / `N/A` / `BLOCKED`
   - **実値・備考** 列: 失敗時の再現手順や実際の値
   - **確認日** 列: `2026-06-XX`
   - **テスター** 列: イニシャル
3. 完了後 `.xlsx` として保存推奨 (色付け・フィルタを残すため)
