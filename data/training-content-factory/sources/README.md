
# sources 폴더 사용법

이 폴더는 **교육 컨텐츠 생성의 기준이 되는 “근거(증거) 소스”를 정리**해 두는 공간입니다.

원칙
- 한 “트랙/모듈”은 **1~3개의 기준 소스**(자격증 시험 범위 + 공식 레퍼런스)를 먼저 고정합니다.
- LLM(예: Claude Code)은 **/sources에 있는 파일만 근거로** lesson/quiz/lab을 생성하게 합니다.
- /sources/_index.yaml 에 모든 소스를 등록해서, evidence pack 생성 시 추적 가능하게 합니다.

기록 규칙
- 각 소스 md 파일 상단에 `URL`, `last_checked(2026-02-16)`, `track`, `tags`를 적습니다.
- “원문을 통째로 복사”하기보다는, **(1) 링크 + (2) 사용해야 할 섹션 + (3) 교육 목적으로 필요한 요약/추출** 형태로 유지합니다.

업데이트
- 자격증 시험 버전이 바뀌면, 우선 **시험 페이지(범위/체크리스트)** 를 업데이트하고,
  그 다음 공식 레퍼런스(자바 API / JLS / Spring / Oracle docs) 링크를 점검합니다.
