
# ORACLE MASTER Bronze DBA 2019 — 1Z0-085-JPN (Bronze DBA Oracle Database Fundamentals)

- track: sql
- type: exam-objectives
- language: ja
- last_checked: 2026-02-16
- URL: https://www.oracle.com/jp/education/certification/certification-exam-list/bronze-dba-fundamentals-1z0-085-exam/

시험 메타(공식 페이지 기준)
- 120분 / 70문항 / 합격라인 65%

범위(“시험 내용 체크리스트” 요약)
- DB/SQL 기초(관계형, 인스턴스/DB 컴포넌트, 파일, 관리 도구, 주요 용어, 운영 포인트)
- 설치/DB 생성
- EM Database Express / SQL*Plus 등 관리 도구 사용
- 네트워크 환경(리스너/클라이언트 접속)
- 인스턴스 관리(기동/중지, 파라미터, 메모리 컴포넌트)
- 저장 구조(Undo/일관성 포함), 사용자·권한·롤, 스키마 오브젝트

교육 설계 메모
- “SQL만”이 아니라 DBA 기초(인스턴스/스토리지/보안/툴)까지 포함 → 사내 DB 운영/개발 협업 교육에 적합.
