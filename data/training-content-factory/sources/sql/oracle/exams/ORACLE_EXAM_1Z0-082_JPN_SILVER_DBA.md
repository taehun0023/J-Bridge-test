
# ORACLE MASTER Silver DBA 2019 — 1Z0-082-JPN (Oracle Database Administration I)

- track: sql
- type: exam-objectives
- language: ja
- last_checked: 2026-02-16

시험 메타(공식 페이지 기준)
- 120분 / 72문항 / 합격라인 60%

범위(“시험 내용 체크리스트” 요약)
- 아키텍처(메모리/프로세스, 논리·물리 구조)
- 인스턴스 관리(기동/중지, 성능/진단 뷰, ADR, alert/trace, 파라미터 파일)
- 사용자/롤/권한/프로파일/인증
- 스토리지(세그먼트/압축/공간 관리)
- 데이터 이동(External table, Data Pump, SQL*Loader)
- 툴(DBCA, EM, SQL Developer, SQL*Plus)
- Oracle Net Services(리스너/네이밍/접속)
- 테이블스페이스/데이터파일/OMF
- UNDO(트랜잭션/REDO 비교, temporary undo)
- + SQL 파트 일부(SELECT/함수/조인/집합/서브쿼리/DML/DDL/인덱스·시노님·시퀀스/제약)

교육 설계 메모
- DBA 트랙은 “운영 시나리오(기동/장애/권한/공간)” 기반 실습이 없으면 텍스트 교육의 효율이 급감함.
