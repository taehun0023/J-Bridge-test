
# ORACLE MASTER Silver SQL 2019 — 1Z0-071-JPN (Oracle Database SQL)

- track: sql
- type: exam-objectives
- language: ja
- last_checked: 2026-02-16
- URL: https://www.oracle.com/jp/education/certification/certification-exam-list/db-sql-1z0-071-exam/

시험 메타(공식 페이지 기준)
- 120분 / 78문항 / 합격라인 63%

범위(“시험 내용 체크리스트” 요약)
- RDB 개념(ERD, 논리/물리, SQL과 DB의 관계)
- SELECT 기초(별칭, DISTINCT, NULL, 산술식, 문자열/대체 인용)
- 제한/정렬 + 치환변수(DEFINE/VERIFY)
- 단일행 함수(문자/숫자/날짜) + 변환함수(TO_CHAR/TO_NUMBER/TO_DATE) + 조건식(NVL/COALESCE 등)
- 그룹함수/집계 + HAVING
- 조인(자기/외부/비등가/카티전) + 서브쿼리(단일/다중/상관)
- 집합 연산자(UNION/INTERSECT/MINUS)
- DML/트랜잭션 + MERGE + 다중 테이블 INSERT
- 인덱스/시노님/시퀀스
- DDL(테이블/제약/임시·외부 테이블) + 뷰
- 권한/롤 + 데이터 딕셔너리 뷰
- 타임존/INTERVAL 데이터 타입

교육 설계 메모
- “문법 나열”보다 **데이터 모델링 → 조회 → 집계 → 변경(트랜잭션) → 성능(인덱스)** 흐름으로 설계하면 실무에 붙는다.
