시험 메타(공식 페이지 기준)
- 시험명: Java SE Bronze
- 시험번호: 1Z0-818-JPN
- 형식: 객관식
- 시간: 65분 / 60문항 / 합격라인 60%

범위(“시험 내용 체크리스트”를 교육 목차로 변환)
1) Java 프로그램 흐름
- 컴파일/실행, Java 기술 특징, Java 플랫폼 에디션 개요

2) 데이터 선언/사용
- 기본형 vs 참조형, 변수/상수/스코프, 1차원 배열, 커맨드라인 args

3) 연산자/분기
- 주요 연산자, 우선순위, if/else, switch

4) 반복문
- while/for/향상 for/do-while, 중첩 루프

5) 객체지향 개념
- concrete/abstract/interface, 캡슐화, 다형성

6) 클래스 정의/객체 사용 + 상속/다형성
- 클래스/객체 생성, 오버로딩, 생성자, 접근제어자, static
- 상속/오버라이딩/추상·인터페이스 구현, 캐스팅, package/import

교육 설계 메모
- Bronze는 “문법 암기”가 아니라 **컴파일 단위 / 스코프 / 접근제어 / 다형성** 같은 실무 기초를 정확히 잡는 게 핵심.
- 예제는 반드시 “컴파일이 되는 완전한 코드” 단위로 제공(시험 주의사항 반영).
