시험 메타(공식 페이지 기준)
- 시험명: Java SE 17 Programmer I
- 시험번호: 1Z0-825-JPN
- 시간: 90분 / 60문항 / 합격라인 65%

범위(“시험 내용 체크리스트”를 교육 목차로 변환)
1) Java 개요 + 간단한 프로그램
- main/컴파일/실행, package/import

2) 기본 타입 + 문자열
- 변수 선언/초기화/스코프, var, String(텍스트 블록 포함)
- 1D/2D 배열, ArrayList

3) 연산자 + 제어구조
- if/switch, 반복문, break/continue, switch expression

4) 클래스/인스턴스
- 클래스 정의/인스턴스화/라이프사이클
- 메소드/생성자/오버로딩, static, 접근제어자
- instanceof 패턴 매칭, record, (Java 17) sealed class

5) 상속/인터페이스
- 상속/추상클래스/오버라이딩/다형성 호출/캐스팅
- final class, interface 구현, default/private method

6) 예외
- checked/unchecked/error 구분
- try-catch, try-with-resources, multi-catch, custom exception

교육 설계 메모
- Silver는 “문법+문제풀이” 중심이되, 실무와 연결(예: record가 DTO 설계에 주는 의미).
- 예외 파트는 반드시 리소스 누수/rollback 같은 실무 시나리오로 연결.
