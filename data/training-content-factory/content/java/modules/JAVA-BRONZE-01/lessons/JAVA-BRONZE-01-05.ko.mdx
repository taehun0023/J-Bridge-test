## 1) 요점 정리 (5줄)

- `for` 문은 "초기화; 조건; 갱신"의 3부 구성으로, 반복 횟수가 사전에 알려진 경우에 최적이다. (Evidence: E1)
- `while` 문은 조건이 true인 동안 반복하며, 반복 횟수가 불확정인 경우에 적합하다. `do-while` 문은 최소 1회 실행이 보장된다. (Evidence: E2)
- 확장 for 문(for-each)은 배열이나 컬렉션의 전체 요소를 순서대로 처리하는 간결한 구문이며, 인덱스 조작이 불필요한 경우에 권장된다. (Evidence: E3)
- `break`는 루프를 즉시 탈출하고, `continue`는 현재 이터레이션을 건너뛰고 다음 이터레이션으로 진행한다. (Evidence: E4)
- 라벨 붙은 `break` / `continue`는 중첩된 루프의 바깥쪽 루프를 제어할 때 사용한다. (Evidence: E5)

## 2) 개념

### for 문

✅ 결론: 반복 횟수를 알고 있는 경우에 최적.

```java
for (초기화; 조건; 갱신) {
    // 루프 본체
}
```

(Evidence: E1)

실행 순서:
1. **초기화** -- 루프 변수를 선언·초기화 (1회만)
2. **조건 평가** -- true이면 루프 본체 실행, false이면 루프 종료
3. **루프 본체** -- 처리 실행
4. **갱신** -- 루프 변수 갱신
5. 2로 돌아감

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);  // 0, 1, 2, 3, 4
}
// i는 여기서 접근할 수 없다 (스코프 밖)
```

💡 암기법: for 문의 3개 부분 = "시작; 언제까지; 다음으로"

### for 문의 응용

✅ 결론: 초기화·조건·갱신은 생략 가능하다.

```java
// 역순 루프
for (int i = 10; i >= 0; i--) {
    System.out.println(i);  // 10, 9, 8, ... 0
}

// 2씩 증가
for (int i = 0; i < 10; i += 2) {
    System.out.println(i);  // 0, 2, 4, 6, 8
}

// 복수 변수의 초기화
for (int i = 0, j = 10; i < j; i++, j--) {
    System.out.println(i + " " + j);
}
```

### while 문

✅ 결론: 조건이 true인 동안 계속 반복한다. 횟수 불확정 루프에 최적.

```java
while (조건) {
    // 루프 본체
}
```

(Evidence: E2)

```java
int count = 0;
while (count < 5) {
    System.out.println(count);  // 0, 1, 2, 3, 4
    count++;
}
```

⚠️ 조건이 영원히 false가 되지 않으면 **무한 루프**가 된다. 루프 본체 안에서 조건에 영향을 주는 변수를 반드시 갱신해야 한다.

### do-while 문

✅ 결론: 최소 1회 실행이 보장된다. 조건 판정은 루프 본체 이후.

```java
do {
    // 루프 본체 (최소 1회 실행)
} while (조건);
```

(Evidence: E2)

```java
int num = 10;
do {
    System.out.println(num);  // 10 (1회만 실행됨)
    num++;
} while (num < 5);  // 조건은 false이지만 이미 1회 실행 완료
```

while 문과의 차이:

| 항목 | `while` | `do-while` |
|---|---|---|
| 조건 판정 | 루프 전 | 루프 후 |
| 최소 실행 횟수 | 0회 | 1회 |
| 세미콜론 | 불필요 | `while(조건);` 뒤에 필요 |

### 확장 for 문 (for-each)

✅ 결론: 배열이나 컬렉션의 전체 요소를 간결하게 처리한다.

```java
for (타입 변수명 : 배열또는Iterable) {
    // 각 요소 처리
}
```

(Evidence: E3)

```java
int[] numbers = {10, 20, 30, 40, 50};
for (int n : numbers) {
    System.out.println(n);  // 10, 20, 30, 40, 50
}

String[] names = {"Alice", "Bob", "Carol"};
for (String name : names) {
    System.out.println("Hello, " + name);
}
```

확장 for 문의 제약:
- 인덱스에 접근할 수 없다 (몇 번째인지 알 수 없다)
- 요소를 추가·삭제할 수 없다
- 역순 순회를 할 수 없다

💡 실무 규칙: 인덱스가 불필요하면 확장 for 문을 사용한다. 코드가 간결해지고 버그도 줄어든다.

### break

✅ 결론: 루프를 즉시 탈출한다.

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // i가 5가 된 시점에서 루프 종료
    }
    System.out.println(i);  // 0, 1, 2, 3, 4
}
```

(Evidence: E4)

`break`는 `switch` 문뿐만 아니라 `for`, `while`, `do-while` 모든 루프에서 사용 가능하다.

### continue

✅ 결론: 현재 이터레이션을 건너뛰고 다음 이터레이션으로 진행한다.

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // 짝수를 건너뜀
    }
    System.out.println(i);  // 1, 3, 5, 7, 9
}
```

(Evidence: E4)

`continue`는:
- `for` 문 → 갱신식으로 이동
- `while` / `do-while` 문 → 조건식 재평가로 이동

### 라벨 붙은 break / continue

✅ 결론: 중첩된 루프의 바깥쪽 루프를 제어할 수 있다.

```java
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) {
            break outer;  // 바깥쪽 for 루프까지 탈출
        }
        System.out.println(i + "," + j);
    }
}
```

출력:

```
0,0
0,1
0,2
1,0
```

(Evidence: E5)

라벨 없는 `break`는 안쪽 루프만 빠져나오지만, 라벨 붙은 `break`를 사용하면 바깥쪽 루프까지 한꺼번에 탈출할 수 있다.

### 무한 루프 패턴

✅ 결론: 의도적인 무한 루프는 while(true) 또는 for(;;)로 작성한다.

```java
// 패턴 1: while(true)
while (true) {
    String input = scanner.nextLine();
    if ("quit".equals(input)) {
        break;  // break로 탈출
    }
    System.out.println("입력: " + input);
}

// 패턴 2: for(;;) — 3개 부분을 모두 생략
for (;;) {
    // break로 탈출할 때까지 무한 반복
}
```

무한 루프는 `break`로 탈출하는 것이 일반적이다. 사용자 입력 대기나 서버의 메인 루프에서 사용된다.

## 3) 예제 (2개)

### 예제 1: 배열의 합계와 평균 (확장 for 문)

확장 for 문을 사용하여 배열의 합계와 평균을 계산하는 예.

```java
public class ArrayStats {
    public static void main(String[] args) {
        int[] scores = {85, 92, 78, 96, 64};

        // 확장 for 문으로 합계 계산
        int sum = 0;
        for (int score : scores) {
            sum += score;
        }

        double average = (double) sum / scores.length;

        System.out.println("합계: " + sum);
        System.out.println("평균: " + average);
        System.out.println("과목수: " + scores.length);

        // 최고점 찾기
        int max = scores[0];
        for (int score : scores) {
            if (score > max) {
                max = score;
            }
        }
        System.out.println("최고점: " + max);
    }
}
```

출력 결과:

```
합계: 415
평균: 83.0
과목수: 5
최고점: 96
```

포인트:
- 확장 for 문은 인덱스를 의식하지 않고 전체 요소를 처리할 수 있어 합계 계산에 최적
- 평균 계산에서는 `(double) sum / scores.length`로 캐스트하여 부동 소수점 나눗셈으로 만든다
- 최댓값 탐색도 확장 for 문으로 간결하게 작성 가능

### 예제 2: 중첩 루프와 라벨 붙은 break

구구단을 출력하고, 특정 조건에서 라벨 붙은 break를 사용하는 예.

```java
public class MultiplicationTable {
    public static void main(String[] args) {
        // 구구단 출력
        System.out.println("=== 구구단 ===");
        for (int i = 1; i <= 9; i++) {
            for (int j = 1; j <= 9; j++) {
                System.out.printf("%3d", i * j);
            }
            System.out.println();
        }

        // 라벨 붙은 break: 곱이 50을 넘는 첫 번째 조합 찾기
        System.out.println("\n=== 곱이 50을 넘는 첫 번째 조합 ===");
        search:
        for (int i = 1; i <= 9; i++) {
            for (int j = 1; j <= 9; j++) {
                if (i * j > 50) {
                    System.out.println(i + " x " + j + " = " + (i * j));
                    break search;  // 바깥쪽 루프까지 탈출
                }
            }
        }
    }
}
```

출력 결과(일부 발췌):

```
=== 구구단 ===
  1  2  3  4  5  6  7  8  9
  2  4  6  8 10 12 14 16 18
  ...
  9 18 27 36 45 54 63 72 81

=== 곱이 50을 넘는 첫 번째 조합 ===
6 x 9 = 54
```

포인트:
- 중첩 `for` 문으로 이차원적 처리(구구단 출력)가 가능하다
- `System.out.printf("%3d", ...)`로 자릿수 맞춤 형식 출력이 가능하다
- 라벨 붙은 `break search;`로 바깥쪽 루프까지 탈출하여 조건을 만족하는 첫 번째 조합만 표시한다

## 4) 흔한 실수 / 함정 (5개)

⚠️ 실수: while 문에서 루프 변수 갱신을 잊어 무한 루프가 됨 → 대책: 루프 본체 안에서 조건에 영향을 주는 변수를 반드시 갱신한다. 잊기 쉬우면 `for` 문을 사용한다

⚠️ 실수: 확장 for 문에서 인덱스를 사용하려 함 → 대책: 인덱스가 필요한 경우에는 통상적인 `for` 문을 사용한다. 확장 for 문은 인덱스 불필요한 경우 전용

⚠️ 실수: do-while 문 끝의 세미콜론을 잊음(`} while (조건)` <- 세미콜론 없음) → 대책: `do { ... } while (조건);` 끝에 세미콜론이 필요함을 기억한다

⚠️ 실수: for 문의 조건식을 잘못 써서 1회 많거나 적게 반복(off-by-one 에러) → 대책: `< n`은 n회, `<= n`은 n+1회 실행. 경곗값을 테스트하는 습관을 들인다

⚠️ 실수: `continue` 뒤에 루프 변수를 갱신하는 처리를 배치하여 건너뜀 → 대책: `while` 문에서 `continue`를 사용할 때 루프 변수 갱신은 `continue` 앞에 한다

## 5) 체크리스트

- [ ] `for` 문의 3부 구성(초기화; 조건; 갱신)과 실행 순서를 설명할 수 있는가
- [ ] `while` 문과 `do-while` 문의 차이(최소 실행 횟수)를 설명할 수 있는가
- [ ] 확장 for 문(for-each)의 구문과 사용 조건을 이해하고 있는가
- [ ] 확장 for 문의 제약(인덱스 불가, 변경 불가)을 나열할 수 있는가
- [ ] `break`와 `continue`의 동작 차이를 구체적 예로 보여줄 수 있는가
- [ ] 라벨 붙은 `break`의 사용법과 용도를 이해하고 있는가
- [ ] 무한 루프 패턴(`while(true)` / `for(;;)`)과 탈출 방법을 알고 있는가
- [ ] off-by-one 에러를 방지하기 위한 경곗값 검사 방법을 이해하고 있는가
