## 1) 要点まとめ（5行）

- Javaの主要な演算子は算術（`+`, `-`, `*`, `/`, `%`）、比較（`==`, `!=`, `<`, `>`, `<=`, `>=`）、論理（`&&`, `||`, `!`）、ビット（`&`, `|`, `^`, `~`, `<<`, `>>`）の4カテゴリに分類される。(Evidence: E1)
- 演算子には優先順位と結合性があり、意図しない計算結果を防ぐために括弧 `()` を積極的に使用すべきである。(Evidence: E2)
- 小さい型から大きい型への変換（拡張変換/widening）は自動的に行われ、データ損失はない。(Evidence: E3)
- 大きい型から小さい型への変換（縮小変換/narrowing）は明示的なキャスト `(型)` が必要であり、データが切り捨てられる可能性がある。(Evidence: E4)
- 算術演算時、`byte`, `short`, `char` は自動的に `int` に昇格（promotion）される。片方が `long`, `float`, `double` であれば相手もそれに合わせて昇格する。(Evidence: E5)

## 2) 概念

### 算術演算子

✅ 結論: 四則演算と剰余で数値を計算する。

| 演算子 | 意味 | 例 | 結果 |
|---|---|---|---|
| `+` | 加算 | `5 + 3` | `8` |
| `-` | 減算 | `5 - 3` | `2` |
| `*` | 乗算 | `5 * 3` | `15` |
| `/` | 除算 | `5 / 3` | `1`（整数除算） |
| `%` | 剰余 | `5 % 3` | `2` |

整数同士の除算 `/` は**小数点以下が切り捨てられる**。浮動小数点の結果が欲しい場合は、少なくとも一方を `double` にする必要がある。(Evidence: E1)

```java
System.out.println(5 / 3);     // 1（整数除算）
System.out.println(5.0 / 3);   // 1.6666666666666667（浮動小数点除算）
System.out.println(5 / 0);     // ArithmeticException（実行時エラー）
System.out.println(5.0 / 0);   // Infinity（浮動小数点のゼロ除算）
```

💡 覚え方: int / int = int（切り捨て）、double が混ざれば double になる

### インクリメント・デクリメント

✅ 結論: `++` / `--` には前置と後置があり、式中の評価タイミングが異なる。

```java
int a = 5;
int b = a++;  // b = 5, a = 6（後置: 代入してから加算）
int c = ++a;  // c = 7, a = 7（前置: 加算してから代入）
```

### 比較演算子

✅ 結論: 2つの値を比較し、boolean型の結果を返す。

| 演算子 | 意味 | 例 | 結果 |
|---|---|---|---|
| `==` | 等しい | `5 == 3` | `false` |
| `!=` | 等しくない | `5 != 3` | `true` |
| `<` | より小さい | `5 < 3` | `false` |
| `>` | より大きい | `5 > 3` | `true` |
| `<=` | 以下 | `5 <= 5` | `true` |
| `>=` | 以上 | `5 >= 6` | `false` |

⚠️ 参照型に `==` を使うと**参照の比較**（同一オブジェクトか）となる。値の比較には `.equals()` メソッドを使用する。(Evidence: E6)

```java
String s1 = new String("hello");
String s2 = new String("hello");
System.out.println(s1 == s2);      // false（異なるオブジェクト）
System.out.println(s1.equals(s2)); // true（値が同じ）
```

### 論理演算子

✅ 結論: 条件式を組み合わせるための演算子。短絡評価に注意。

| 演算子 | 意味 | 短絡評価 |
|---|---|---|
| `&&` | 論理AND | あり（左がfalseなら右を評価しない） |
| `\|\|` | 論理OR | あり（左がtrueなら右を評価しない） |
| `!` | 論理NOT | — |
| `&` | 論理AND | なし（両方を常に評価） |
| `\|` | 論理OR | なし（両方を常に評価） |

(Evidence: E1)

💡 覚え方: `&&` / `||` = 短絡あり（効率的）、`&` / `|` = 短絡なし（両方評価）

```java
int x = 0;
if (x != 0 && 10 / x > 1) {  // 短絡評価: x==0 なので右辺は評価されない → 安全
    System.out.println("OK");
}
```

### ビット演算子

✅ 結論: 整数のビット単位で演算を行う。

| 演算子 | 意味 | 例 (`a=5`, `b=3`) | 結果 |
|---|---|---|---|
| `&` | AND | `5 & 3` → `0101 & 0011` | `1` (`0001`) |
| `\|` | OR | `5 \| 3` → `0101 \| 0011` | `7` (`0111`) |
| `^` | XOR | `5 ^ 3` → `0101 ^ 0011` | `6` (`0110`) |
| `~` | NOT | `~5` → `~00000101` | `-6` |
| `<<` | 左シフト | `5 << 1` | `10` |
| `>>` | 右シフト（符号付き） | `5 >> 1` | `2` |
| `>>>` | 右シフト（符号なし） | `-1 >>> 28` | `15` |

(Evidence: E1)

### 演算子の優先順位

✅ 結論: 優先順位を覚えるより括弧を使え。

主要な優先順位（高い順）:

1. `()` — 括弧（最優先）
2. `++`, `--`, `!`, `~` — 単項演算子
3. `*`, `/`, `%` — 乗除算
4. `+`, `-` — 加減算
5. `<<`, `>>`, `>>>` — シフト
6. `<`, `>`, `<=`, `>=` — 比較
7. `==`, `!=` — 等値
8. `&`, `^`, `|` — ビット演算
9. `&&`, `||` — 論理演算
10. `=`, `+=`, `-=` 等 — 代入

(Evidence: E2)

💡 実務ルール: 迷ったら括弧を付ける。コードの意図が明確になる。

### 暗黙の拡張変換（widening）

✅ 結論: 小さい型から大きい型への変換は自動で行われる。

```
byte → short → int → long → float → double
              ↑
             char
```

```java
int i = 100;
long l = i;      // int → long: 自動変換（データ損失なし）
double d = l;    // long → double: 自動変換
```

(Evidence: E3)

### 明示的な縮小変換（narrowing cast）

✅ 結論: 大きい型から小さい型への変換はキャスト必須。

```java
double d = 3.99;
int i = (int) d;   // 3（小数部切り捨て、四捨五入ではない）

int big = 300;
byte b = (byte) big;  // 44（オーバーフロー: 300 % 256 = 44）
```

キャストを省略するとコンパイルエラーになる。(Evidence: E4)

### 算術演算時の型昇格（promotion）

✅ 結論: byte, short, char は演算時に自動で int に昇格する。

```java
byte a = 10;
byte b = 20;
// byte c = a + b;  // コンパイルエラー！a + b は int 型になる
int c = a + b;      // OK: int 型で受ける
byte d = (byte)(a + b);  // OK: 明示的キャストで byte に戻す
```

昇格ルール:
1. `byte`, `short`, `char` → `int` に昇格
2. 片方が `long` → 両方 `long` に昇格
3. 片方が `float` → 両方 `float` に昇格
4. 片方が `double` → 両方 `double` に昇格

(Evidence: E5)

## 3) 例（2つ）

### 例1: 整数除算と浮動小数点除算の違い

同じ数値の除算でも、型によって結果が異なることを示す例。

```java
public class DivisionDemo {
    public static void main(String[] args) {
        // 整数除算: 小数部は切り捨て
        int a = 7;
        int b = 2;
        System.out.println("int / int = " + (a / b));         // 3

        // 片方を double にすると浮動小数点除算
        System.out.println("double / int = " + (7.0 / 2));    // 3.5

        // キャストで浮動小数点除算にする
        System.out.println("(double)int / int = " + ((double) a / b));  // 3.5

        // 剰余の活用: 偶数・奇数判定
        for (int i = 1; i <= 5; i++) {
            String type = (i % 2 == 0) ? "偶数" : "奇数";
            System.out.println(i + " は " + type);
        }
    }
}
```

出力結果:

```
int / int = 3
double / int = 3.5
(double)int / int = 3.5
1 は 奇数
2 は 偶数
3 は 奇数
4 は 偶数
5 は 奇数
```

ポイント:
- `7 / 2` は `3`（切り捨て）だが、`7.0 / 2` は `3.5` になる
- `(double) a / b` とキャストすることで、変数を使った場合でも浮動小数点除算にできる
- `%`（剰余）演算子は偶奇判定やループ処理でよく使用される

### 例2: 型昇格とキャストの実践

byte同士の演算結果がintになること、およびキャスト時のオーバーフローを示す例。

```java
public class PromotionDemo {
    public static void main(String[] args) {
        // byte同士の演算 → int に昇格
        byte x = 50;
        byte y = 60;
        // byte z = x + y;  // コンパイルエラー！
        int sum = x + y;
        System.out.println("byte + byte → int: " + sum);  // 110

        // キャストで byte に戻す
        byte result = (byte)(x + y);
        System.out.println("(byte)(50 + 60) = " + result);  // 110（範囲内なのでOK）

        // オーバーフローの例
        byte overflow = (byte)(200);
        System.out.println("(byte)200 = " + overflow);  // -56

        // char → int への暗黙変換
        char ch = 'A';
        int code = ch;  // 自動変換
        System.out.println("'A' の文字コード: " + code);  // 65
    }
}
```

出力結果:

```
byte + byte → int: 110
(byte)(50 + 60) = 110
(byte)200 = -56
'A' の文字コード: 65
```

ポイント:
- `byte + byte` の結果は `int` 型になるため、`byte` 変数に直接代入するとコンパイルエラー
- `(byte)200` は byte の範囲（-128〜127）を超えるため、オーバーフローして `-56` になる（200 - 256 = -56）
- `char` は整数値に自動変換でき、`'A'` は Unicode値の `65` になる

## 4) よくあるミス／落とし穴（5つ）

⚠️ ミス: 整数同士の除算で小数点以下の結果を期待する → 対策: 少なくとも一方を `double` にする。`(double) a / b` または `a / (double) b`

⚠️ ミス: `byte` や `short` の演算結果を同じ型に代入する（`byte c = a + b;`） → 対策: 結果は `int` に昇格されるので、`int` で受けるか `(byte)` キャストする

⚠️ ミス: 参照型に `==` を使って値を比較する → 対策: `String` 等の値比較には `.equals()` を使う。`==` はプリミティブ型のみに使用する

⚠️ ミス: キャスト時のオーバーフローを見落とす → 対策: 変換先の型の範囲を確認する。`(byte)200` は `-56` になることを理解する

⚠️ ミス: 演算子の優先順位を誤り、意図しない計算結果になる → 対策: 迷ったら括弧 `()` で明示する。`a + b * c` は `a + (b * c)` と同じ
