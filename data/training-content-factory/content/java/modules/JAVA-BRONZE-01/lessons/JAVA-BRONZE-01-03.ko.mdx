## 1) 요점 정리 (5줄)

- Java의 주요 연산자는 산술(`+`, `-`, `*`, `/`, `%`), 비교(`==`, `!=`, `<`, `>`, `<=`, `>=`), 논리(`&&`, `||`, `!`), 비트(`&`, `|`, `^`, `~`, `<<`, `>>`)의 4가지 카테고리로 분류된다. (Evidence: E1)
- 연산자에는 우선순위와 결합성이 있으며, 의도하지 않은 계산 결과를 방지하기 위해 괄호 `()`를 적극적으로 사용해야 한다. (Evidence: E2)
- 작은 타입에서 큰 타입으로의 변환(확대 변환/widening)은 자동으로 수행되며, 데이터 손실이 없다. (Evidence: E3)
- 큰 타입에서 작은 타입으로의 변환(축소 변환/narrowing)은 명시적 캐스트 `(타입)`이 필요하며, 데이터가 잘릴 수 있다. (Evidence: E4)
- 산술 연산 시 `byte`, `short`, `char`는 자동으로 `int`로 승격(promotion)된다. 한쪽이 `long`, `float`, `double`이면 상대방도 그에 맞춰 승격된다. (Evidence: E5)

## 2) 개념

### 산술 연산자

✅ 결론: 사칙연산과 나머지로 수치를 계산한다.

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---|
| `+` | 덧셈 | `5 + 3` | `8` |
| `-` | 뺄셈 | `5 - 3` | `2` |
| `*` | 곱셈 | `5 * 3` | `15` |
| `/` | 나눗셈 | `5 / 3` | `1`(정수 나눗셈) |
| `%` | 나머지 | `5 % 3` | `2` |

정수끼리의 나눗셈 `/`은 **소수점 이하가 버려진다**. 부동 소수점 결과가 필요한 경우, 최소 한쪽을 `double`로 만들어야 한다. (Evidence: E1)

```java
System.out.println(5 / 3);     // 1 (정수 나눗셈)
System.out.println(5.0 / 3);   // 1.6666666666666667 (부동 소수점 나눗셈)
System.out.println(5 / 0);     // ArithmeticException (런타임 에러)
System.out.println(5.0 / 0);   // Infinity (부동 소수점의 0 나눗셈)
```

💡 암기법: int / int = int(버림), double이 섞이면 double이 된다

### 증감 연산자

✅ 결론: `++` / `--`에는 전위와 후위가 있으며, 식 내에서의 평가 타이밍이 다르다.

```java
int a = 5;
int b = a++;  // b = 5, a = 6 (후위: 대입 후 증가)
int c = ++a;  // c = 7, a = 7 (전위: 증가 후 대입)
```

### 비교 연산자

✅ 결론: 두 값을 비교하고 boolean 타입의 결과를 반환한다.

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---|
| `==` | 같다 | `5 == 3` | `false` |
| `!=` | 같지 않다 | `5 != 3` | `true` |
| `<` | 보다 작다 | `5 < 3` | `false` |
| `>` | 보다 크다 | `5 > 3` | `true` |
| `<=` | 이하 | `5 <= 5` | `true` |
| `>=` | 이상 | `5 >= 6` | `false` |

⚠️ 참조 타입에 `==`를 사용하면 **참조 비교**(같은 객체인지)가 된다. 값 비교에는 `.equals()` 메서드를 사용한다. (Evidence: E6)

```java
String s1 = new String("hello");
String s2 = new String("hello");
System.out.println(s1 == s2);      // false (서로 다른 객체)
System.out.println(s1.equals(s2)); // true (값이 동일)
```

### 논리 연산자

✅ 결론: 조건식을 결합하기 위한 연산자. 단축 평가에 주의.

| 연산자 | 의미 | 단축 평가 |
|---|---|---|
| `&&` | 논리 AND | 있음(왼쪽이 false면 오른쪽 평가 안 함) |
| `\|\|` | 논리 OR | 있음(왼쪽이 true면 오른쪽 평가 안 함) |
| `!` | 논리 NOT | -- |
| `&` | 논리 AND | 없음(양쪽 항상 평가) |
| `\|` | 논리 OR | 없음(양쪽 항상 평가) |

(Evidence: E1)

💡 암기법: `&&` / `||` = 단축 있음(효율적), `&` / `|` = 단축 없음(양쪽 평가)

```java
int x = 0;
if (x != 0 && 10 / x > 1) {  // 단축 평가: x==0이므로 오른쪽은 평가되지 않음 → 안전
    System.out.println("OK");
}
```

### 비트 연산자

✅ 결론: 정수의 비트 단위로 연산을 수행한다.

| 연산자 | 의미 | 예 (`a=5`, `b=3`) | 결과 |
|---|---|---|---|
| `&` | AND | `5 & 3` → `0101 & 0011` | `1` (`0001`) |
| `\|` | OR | `5 \| 3` → `0101 \| 0011` | `7` (`0111`) |
| `^` | XOR | `5 ^ 3` → `0101 ^ 0011` | `6` (`0110`) |
| `~` | NOT | `~5` → `~00000101` | `-6` |
| `<<` | 왼쪽 시프트 | `5 << 1` | `10` |
| `>>` | 오른쪽 시프트(부호 있음) | `5 >> 1` | `2` |
| `>>>` | 오른쪽 시프트(부호 없음) | `-1 >>> 28` | `15` |

(Evidence: E1)

### 연산자 우선순위

✅ 결론: 우선순위를 외우려 하기보다 괄호를 사용하라.

주요 우선순위 (높은 순):

1. `()` -- 괄호(최우선)
2. `++`, `--`, `!`, `~` -- 단항 연산자
3. `*`, `/`, `%` -- 곱셈/나눗셈
4. `+`, `-` -- 덧셈/뺄셈
5. `<<`, `>>`, `>>>` -- 시프트
6. `<`, `>`, `<=`, `>=` -- 비교
7. `==`, `!=` -- 등가
8. `&`, `^`, `|` -- 비트 연산
9. `&&`, `||` -- 논리 연산
10. `=`, `+=`, `-=` 등 -- 대입

(Evidence: E2)

💡 실무 규칙: 헷갈리면 괄호를 붙인다. 코드의 의도가 명확해진다.

### 암묵적 확대 변환 (widening)

✅ 결론: 작은 타입에서 큰 타입으로의 변환은 자동으로 수행된다.

```
byte → short → int → long → float → double
              ↑
             char
```

```java
int i = 100;
long l = i;      // int → long: 자동 변환(데이터 손실 없음)
double d = l;    // long → double: 자동 변환
```

(Evidence: E3)

### 명시적 축소 변환 (narrowing cast)

✅ 결론: 큰 타입에서 작은 타입으로의 변환은 캐스트가 필수.

```java
double d = 3.99;
int i = (int) d;   // 3 (소수부 버림, 반올림이 아님)

int big = 300;
byte b = (byte) big;  // 44 (오버플로: 300 % 256 = 44)
```

캐스트를 생략하면 컴파일 에러가 된다. (Evidence: E4)

### 산술 연산 시의 타입 승격 (promotion)

✅ 결론: byte, short, char는 연산 시 자동으로 int로 승격된다.

```java
byte a = 10;
byte b = 20;
// byte c = a + b;  // 컴파일 에러! a + b는 int 타입이 됨
int c = a + b;      // OK: int 타입으로 받음
byte d = (byte)(a + b);  // OK: 명시적 캐스트로 byte로 되돌림
```

승격 규칙:
1. `byte`, `short`, `char` → `int`로 승격
2. 한쪽이 `long` → 양쪽 `long`으로 승격
3. 한쪽이 `float` → 양쪽 `float`으로 승격
4. 한쪽이 `double` → 양쪽 `double`으로 승격

(Evidence: E5)

## 3) 예제 (2개)

### 예제 1: 정수 나눗셈과 부동 소수점 나눗셈의 차이

같은 수치의 나눗셈이라도 타입에 따라 결과가 달라지는 예.

```java
public class DivisionDemo {
    public static void main(String[] args) {
        // 정수 나눗셈: 소수부 버림
        int a = 7;
        int b = 2;
        System.out.println("int / int = " + (a / b));         // 3

        // 한쪽을 double로 하면 부동 소수점 나눗셈
        System.out.println("double / int = " + (7.0 / 2));    // 3.5

        // 캐스트로 부동 소수점 나눗셈으로 변환
        System.out.println("(double)int / int = " + ((double) a / b));  // 3.5

        // 나머지 활용: 짝수/홀수 판정
        for (int i = 1; i <= 5; i++) {
            String type = (i % 2 == 0) ? "짝수" : "홀수";
            System.out.println(i + " 은/는 " + type);
        }
    }
}
```

출력 결과:

```
int / int = 3
double / int = 3.5
(double)int / int = 3.5
1 은/는 홀수
2 은/는 짝수
3 은/는 홀수
4 은/는 짝수
5 은/는 홀수
```

포인트:
- `7 / 2`는 `3`(버림)이지만, `7.0 / 2`는 `3.5`가 된다
- `(double) a / b`로 캐스트하면 변수를 사용한 경우에도 부동 소수점 나눗셈이 가능하다
- `%`(나머지) 연산자는 짝홀 판정이나 루프 처리에서 자주 사용된다

### 예제 2: 타입 승격과 캐스트의 실전

byte끼리의 연산 결과가 int가 되는 것, 그리고 캐스트 시 오버플로를 보여주는 예.

```java
public class PromotionDemo {
    public static void main(String[] args) {
        // byte끼리의 연산 → int로 승격
        byte x = 50;
        byte y = 60;
        // byte z = x + y;  // 컴파일 에러!
        int sum = x + y;
        System.out.println("byte + byte → int: " + sum);  // 110

        // 캐스트로 byte로 되돌림
        byte result = (byte)(x + y);
        System.out.println("(byte)(50 + 60) = " + result);  // 110 (범위 내이므로 OK)

        // 오버플로 예
        byte overflow = (byte)(200);
        System.out.println("(byte)200 = " + overflow);  // -56

        // char → int로의 암묵적 변환
        char ch = 'A';
        int code = ch;  // 자동 변환
        System.out.println("'A'의 문자 코드: " + code);  // 65
    }
}
```

출력 결과:

```
byte + byte → int: 110
(byte)(50 + 60) = 110
(byte)200 = -56
'A'의 문자 코드: 65
```

포인트:
- `byte + byte`의 결과는 `int` 타입이 되므로 `byte` 변수에 직접 대입하면 컴파일 에러
- `(byte)200`은 byte의 범위(-128~127)를 넘으므로 오버플로되어 `-56`이 된다(200 - 256 = -56)
- `char`는 정수값으로 자동 변환되며, `'A'`는 Unicode 값 `65`가 된다

## 4) 흔한 실수 / 함정 (5개)

⚠️ 실수: 정수끼리의 나눗셈에서 소수점 이하 결과를 기대함 → 대책: 최소 한쪽을 `double`로 만든다. `(double) a / b` 또는 `a / (double) b`

⚠️ 실수: `byte`나 `short`의 연산 결과를 같은 타입에 대입(`byte c = a + b;`) → 대책: 결과는 `int`로 승격되므로 `int`로 받거나 `(byte)` 캐스트한다

⚠️ 실수: 참조 타입에 `==`를 사용하여 값을 비교 → 대책: `String` 등의 값 비교에는 `.equals()`를 사용한다. `==`는 프리미티브 타입에만 사용한다

⚠️ 실수: 캐스트 시 오버플로를 간과 → 대책: 변환 대상 타입의 범위를 확인한다. `(byte)200`이 `-56`이 됨을 이해한다

⚠️ 실수: 연산자 우선순위를 잘못 알아 의도하지 않은 계산 결과를 얻음 → 대책: 헷갈리면 괄호 `()`로 명시한다. `a + b * c`는 `a + (b * c)`와 같다
