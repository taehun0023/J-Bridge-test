## 1) 要点まとめ（5行）

- `for` 文は「初期化; 条件; 更新」の3部構成で、繰り返し回数が事前に分かっている場合に最適である。(Evidence: E1)
- `while` 文は条件がtrueの間繰り返し、繰り返し回数が不定の場合に適する。`do-while` 文は最低1回実行が保証される。(Evidence: E2)
- 拡張for文（for-each）は配列やコレクションの全要素を順に処理する簡潔な構文であり、インデックス操作が不要な場合に推奨される。(Evidence: E3)
- `break` はループを即座に脱出し、`continue` は現在のイテレーションをスキップして次のイテレーションに進む。(Evidence: E4)
- ラベル付き `break` / `continue` はネストしたループの外側ループを制御する場合に使用する。(Evidence: E5)

## 2) 概念

### for文

✅ 結論: 繰り返し回数が分かっている場合に最適。

```java
for (初期化; 条件; 更新) {
    // ループ本体
}
```

(Evidence: E1)

実行順序:
1. **初期化** — ループ変数を宣言・初期化（1回のみ）
2. **条件評価** — trueならループ本体を実行、falseならループ終了
3. **ループ本体** — 処理を実行
4. **更新** — ループ変数を更新
5. 2に戻る

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);  // 0, 1, 2, 3, 4
}
// i はここではアクセスできない（スコープ外）
```

💡 覚え方: for文の3つの部分 = 「始まり; いつまで; 次へ」

### for文の応用

✅ 結論: 初期化・条件・更新は省略可能。

```java
// 逆順ループ
for (int i = 10; i >= 0; i--) {
    System.out.println(i);  // 10, 9, 8, ... 0
}

// 2ずつ増加
for (int i = 0; i < 10; i += 2) {
    System.out.println(i);  // 0, 2, 4, 6, 8
}

// 複数変数の初期化
for (int i = 0, j = 10; i < j; i++, j--) {
    System.out.println(i + " " + j);
}
```

### while文

✅ 結論: 条件がtrueの間ずっと繰り返す。回数不定のループに最適。

```java
while (条件) {
    // ループ本体
}
```

(Evidence: E2)

```java
int count = 0;
while (count < 5) {
    System.out.println(count);  // 0, 1, 2, 3, 4
    count++;
}
```

⚠️ 条件が永遠にfalseにならない場合、**無限ループ**になる。ループ本体内で条件を変化させることを忘れないこと。

### do-while文

✅ 結論: 最低1回は実行が保証される。条件判定はループ本体の後。

```java
do {
    // ループ本体（最低1回実行）
} while (条件);
```

(Evidence: E2)

```java
int num = 10;
do {
    System.out.println(num);  // 10（1回だけ実行される）
    num++;
} while (num < 5);  // 条件は false だが、既に1回実行済み
```

while文との違い:

| 項目 | `while` | `do-while` |
|---|---|---|
| 条件判定 | ループ前 | ループ後 |
| 最低実行回数 | 0回 | 1回 |
| セミコロン | 不要 | `while(条件);` の後に必要 |

### 拡張for文（for-each）

✅ 結論: 配列やコレクションの全要素を簡潔に処理する。

```java
for (型 変数名 : 配列またはIterable) {
    // 各要素の処理
}
```

(Evidence: E3)

```java
int[] numbers = {10, 20, 30, 40, 50};
for (int n : numbers) {
    System.out.println(n);  // 10, 20, 30, 40, 50
}

String[] names = {"Alice", "Bob", "Carol"};
for (String name : names) {
    System.out.println("Hello, " + name);
}
```

拡張for文の制約:
- インデックスにアクセスできない（何番目かが分からない）
- 要素の追加・削除はできない
- 逆順の走査はできない

💡 実務ルール: インデックスが不要なら拡張for文を使う。コードが簡潔になり、バグも減る。

### break

✅ 結論: ループを即座に脱出する。

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // i が 5 になった時点でループ終了
    }
    System.out.println(i);  // 0, 1, 2, 3, 4
}
```

(Evidence: E4)

`break` は `switch` 文だけでなく、`for`, `while`, `do-while` のすべてのループで使用可能。

### continue

✅ 結論: 現在のイテレーションをスキップし、次のイテレーションに進む。

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // 偶数をスキップ
    }
    System.out.println(i);  // 1, 3, 5, 7, 9
}
```

(Evidence: E4)

`continue` は:
- `for` 文 → 更新式に移動
- `while` / `do-while` 文 → 条件式の再評価に移動

### ラベル付きbreak / continue

✅ 結論: ネストしたループの外側ループを制御できる。

```java
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) {
            break outer;  // 外側のforループごと脱出
        }
        System.out.println(i + "," + j);
    }
}
```

出力:

```
0,0
0,1
0,2
1,0
```

(Evidence: E5)

ラベルなしの `break` だと内側のループしか抜けないが、ラベル付き `break` を使えば外側のループまで一度に脱出できる。

### 無限ループパターン

✅ 結論: 意図的な無限ループは while(true) または for(;;) で書く。

```java
// パターン1: while(true)
while (true) {
    String input = scanner.nextLine();
    if ("quit".equals(input)) {
        break;  // breakで脱出
    }
    System.out.println("入力: " + input);
}

// パターン2: for(;;) — 3つの部分をすべて省略
for (;;) {
    // break で脱出するまで無限に繰り返す
}
```

無限ループは `break` で脱出するのが一般的。ユーザー入力待ちやサーバーのメインループで使用される。

## 3) 例（2つ）

### 例1: 配列の合計と平均（拡張for文）

拡張for文を使って配列の合計と平均を計算する例。

```java
public class ArrayStats {
    public static void main(String[] args) {
        int[] scores = {85, 92, 78, 96, 64};

        // 拡張for文で合計を計算
        int sum = 0;
        for (int score : scores) {
            sum += score;
        }

        double average = (double) sum / scores.length;

        System.out.println("合計: " + sum);
        System.out.println("平均: " + average);
        System.out.println("科目数: " + scores.length);

        // 最高点を探す
        int max = scores[0];
        for (int score : scores) {
            if (score > max) {
                max = score;
            }
        }
        System.out.println("最高点: " + max);
    }
}
```

出力結果:

```
合計: 415
平均: 83.0
科目数: 5
最高点: 96
```

ポイント:
- 拡張for文はインデックスを意識せずに全要素を処理できるため、合計計算に最適
- 平均計算では `(double) sum / scores.length` とキャストして浮動小数点除算にする
- 最大値の探索も拡張for文で簡潔に書ける

### 例2: ネストしたループとラベル付きbreak

九九表を出力し、特定の条件でラベル付きbreakを使う例。

```java
public class MultiplicationTable {
    public static void main(String[] args) {
        // 九九表の出力
        System.out.println("=== 九九表 ===");
        for (int i = 1; i <= 9; i++) {
            for (int j = 1; j <= 9; j++) {
                System.out.printf("%3d", i * j);
            }
            System.out.println();
        }

        // ラベル付きbreak: 積が50を超える最初の組み合わせを探す
        System.out.println("\n=== 積が50を超える最初の組み合わせ ===");
        search:
        for (int i = 1; i <= 9; i++) {
            for (int j = 1; j <= 9; j++) {
                if (i * j > 50) {
                    System.out.println(i + " × " + j + " = " + (i * j));
                    break search;  // 外側のループごと脱出
                }
            }
        }
    }
}
```

出力結果（一部抜粋）:

```
=== 九九表 ===
  1  2  3  4  5  6  7  8  9
  2  4  6  8 10 12 14 16 18
  ...
  9 18 27 36 45 54 63 72 81

=== 積が50を超える最初の組み合わせ ===
6 × 9 = 54
```

ポイント:
- ネストした `for` 文で二次元的な処理（九九表の出力）ができる
- `System.out.printf("%3d", ...)` で桁揃えのフォーマット出力が可能
- ラベル付き `break search;` で外側のループごと脱出し、最初に条件を満たした組み合わせだけを表示する

## 4) よくあるミス／落とし穴（5つ）

⚠️ ミス: while文でループ変数の更新を忘れて無限ループになる → 対策: ループ本体内で条件に影響する変数を必ず更新する。忘れやすい場合は `for` 文を使う

⚠️ ミス: 拡張for文でインデックスを使おうとする → 対策: インデックスが必要な場合は通常の `for` 文を使う。拡張for文はインデックス不要な場合専用

⚠️ ミス: do-while文の末尾のセミコロンを忘れる（`} while (条件)` ← セミコロンがない） → 対策: `do { ... } while (条件);` の末尾にはセミコロンが必要であることを覚える

⚠️ ミス: for文の条件式を間違えて1回多くまたは少なくループする（off-by-oneエラー） → 対策: `< n` は n 回、`<= n` は n+1 回の実行。境界値をテストする習慣を付ける

⚠️ ミス: `continue` の後にループ変数を更新する処理を配置してスキップされる → 対策: `while` 文で `continue` を使う場合、ループ変数の更新は `continue` の前に行う
