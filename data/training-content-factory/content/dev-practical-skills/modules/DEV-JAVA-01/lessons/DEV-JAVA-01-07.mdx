## 学習目標

このパートを学習した後、次のことができなければならない。

- for文の初期式・条件式・増減式を区別する。
- コードを決まった回数だけ繰り返す。
- 繰り返しの順序を増加または減少させることができる。
- 繰り返し文で合計と個数を計算する。
- 繰り返し回数と条件式の境界を正確に書く。

## 授業内容

### Part 1. for文の基本構造

**概念説明**

- for文はコードを一定の回数だけ繰り返すときに使う。
- 丸括弧の中には初期式・条件式・増減式を書く。
- 初期式は繰り返しを始める前に一度だけ実行される。
- 条件式がtrueである間、中括弧の内部を繰り返す。
- 一度実行するたびに増減式が実行された後、条件を再び検査する。

**コード文法の分解**

```java
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}
```

| 部分 | 意味 |
|---|---|
| `int i = 1` | 繰り返し変数 i を作り 1 から始める |
| `i <= 3` | i が 3 以下の間繰り返す |
| `i++` | 一度繰り返すたびに i を 1 増やす |
| `{ }` | 繰り返して実行するコード |

**実行の流れ**

| 順序 | i | 条件の結果 | 実行 |
|---|---|---|---|
| 1 | 1 | `1 <= 3` → true | 1 を出力 |
| 2 | 2 | `2 <= 3` → true | 2 を出力 |
| 3 | 3 | `3 <= 3` → true | 3 を出力 |
| 4 | 4 | `4 <= 3` → false | 繰り返し終了 |

**実行結果**

```
1
2
3
```

**問題とは別の例**

```java
for (int count = 0; count < 3; count++) {
    System.out.println("Java");
}
```

```
Java
Java
Java
```

countは0、1、2のときに実行されるので、合計3回繰り返す。

**よくあるミス**

for文の後ろにセミコロンを付けてしまう。

```java
for (int i = 1; i <= 3; i++); {
    System.out.println("Java");
}
```

セミコロンのせいで繰り返すコードがないfor文になってしまう。正しいコードは次のとおりである。

```java
for (int i = 1; i <= 3; i++) {
    System.out.println("Java");
}
```

### Part 2. 増加・減少・間隔の調整

**概念説明**

- 繰り返し変数は必ずしも1ずつ増加する必要はない。
- `i--`を使うと値を1ずつ減少させることができる。
- `i += 2`のように書くと2ずつ増加させることができる。
- 初期値と条件式、増減式は同じ方向に書かなければならない。
- 増減の方向が条件と合わないと、繰り返しが終わらないことがある。

**1ずつ増加**

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

```
1
2
3
4
5
```

**1ずつ減少**

```java
for (int i = 5; i >= 1; i--) {
    System.out.println(i);
}
```

```
5
4
3
2
1
```

**2ずつ増加**

```java
for (int i = 0; i <= 6; i += 2) {
    System.out.println(i);
}
```

```
0
2
4
6
```

**実行の流れ**

- 開始値 0
- → 0 を出力
- → 2 を出力
- → 4 を出力
- → 6 を出力
- → 8 は条件を満たさないので終了

**よくあるミス**

次の繰り返し文はiが減り続けるので終了しない。

```java
for (int i = 1; i <= 5; i--) {
    System.out.println(i);
}
```

正しい増減方向は次のとおりである。

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

### Part 3. 繰り返し回数と範囲

**概念説明**

- `<`と`<=`によって最後に繰り返す値が変わる。
- `i < 5`はiが5になる前に終了する。
- `i <= 5`はiが5のときも実行する。
- 繰り返し回数を間違って計算すると、1回少なくまたは多く実行されることがある。
- このようなエラーを境界値エラーまたはオフバイワンエラーという。

**2つの条件の違い**

```java
for (int i = 1; i < 5; i++) {
    System.out.println(i);
}
```

```
1
2
3
4
```

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

```
1
2
3
4
5
```

**決まった回数だけ繰り返す**

次の形は0から始めて正確に5回繰り返す。

```java
for (int i = 0; i < 5; i++) {
    System.out.println("繰り返し");
}
```

iの値は次のように変化する。

```
0, 1, 2, 3, 4
```

**よくあるミス**

次のコードは5回ではなく6回実行される。

```java
for (int i = 0; i <= 5; i++) {
    System.out.println("繰り返し");
}
```

iが0、1、2、3、4、5のときに実行されるからである。

### Part 4. 合計と個数の計算

**概念説明**

- 繰り返し文の外に変数を作ると、繰り返しの結果を継続して累積できる。
- 合計を計算する変数は一般的に0で初期化する。
- 繰り返すたびに現在の値を合計変数に足す。
- 条件に合う回数を計算するときは、個数変数を1ずつ増加させる。
- 累積変数は繰り返し文が始まるたびに再び作られないよう外側で宣言する。

**合計の計算**

```java
int sum = 0;

for (int i = 1; i <= 5; i++) {
    sum += i;
}

System.out.println(sum);
```

**実行の流れ**

- `sum = 0`
- `sum = 0 + 1` → 1
- `sum = 1 + 2` → 3
- `sum = 3 + 3` → 6
- `sum = 6 + 4` → 10
- `sum = 10 + 5` → 15

**実行結果**

```
15
```

**条件に合う個数の計算**

```java
int count = 0;

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        count++;
    }
}

System.out.println(count);
```

1から10までの偶数は2、4、6、8、10なので結果は次のとおりである。

```
5
```

**よくあるミス**

累積変数を繰り返し文の内部で初期化すると、合計が維持されない。

```java
for (int i = 1; i <= 5; i++) {
    int sum = 0;
    sum += i;
}
```

正しいコードは繰り返し文の外でsumを宣言する。

```java
int sum = 0;

for (int i = 1; i <= 5; i++) {
    sum += i;
}
```
