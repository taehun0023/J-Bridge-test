## 学習目標

このパートを学習した後、次のことができるようになります。

- Java プログラムの基本の形を書ける。
- main メソッドがプログラムの開始点であることがわかる。
- 画面に文字を出力できる。
- print と println の違いを区別できる。
- 1行コメントと複数行コメントを書ける。
- 大文字小文字・二重引用符・セミコロンに関するエラーを見つけられる。

## 授業内容

### Part 1. Java プログラムの基本構造

**概念説明**

- Java のコードはクラスの内部に書く。
- 今はクラスを「プログラムを入れる外側の領域」と理解すればよい。
- Java プログラムを実行すると、main メソッド内部のコードが上から下へ実行される。
- ファイル名が `Main.java` ならクラス名も `Main` にする。
- 中括弧 `{ }` はクラスとメソッドの範囲を表す。
- 実行文の終わりにはセミコロン `;` を付ける。

**コード文法の分解**

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Java 開始");
    }
}
```

| コード | 意味 |
|---|---|
| `public class Main` | Main というプログラム領域を作る。 |
| `public static void main(String[] args)` | プログラムが開始される位置である。 |
| `{ }` | コードが含まれる範囲を表す。 |
| `System.out.println(...)` | 括弧内の内容を画面に出力する。 |
| `;` | 一つの実行文が終わったことを表す。 |

`public`・`static`・`String[]` の詳しい意味は後のパートで学習する。
このパートでは main 宣言全体を「Java プログラムの開始の形」として覚える。

**問題とは別の例**

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("最初のJavaプログラム");
    }
}
```

**実行の流れと結果**

1. Java が main メソッドを探す。
2. main 内部の最初の実行文を実行する。
3. 画面に文を出力する。
4. これ以上実行するコードがないのでプログラムが終わる。

```
最初のJavaプログラム
```

**よくあるミス**

```java
public class main {                            // クラス名の大文字小文字が間違っている
    public static void Main(String[] args) {   // main の大文字小文字が間違っている
        system.out.println("Hello")            // System とセミコロンのエラー
    }
}
```

- クラス名とファイル名を違うものにする。
- `main` を `Main` と書き間違える。
- 閉じ中括弧 `}` を書き忘れる。
- 実行文の終わりにセミコロンを付けない。
- `System` の最初の文字を小文字で書く。

### Part 2. System.out.println() での出力

**概念説明**

- `System.out.println()` は括弧内の内容を画面に出力する。
- 出力する文字は二重引用符 `" "` で囲まなければならない。
- `println` は内容を出力した後、改行する。
- したがって `println` を2回使うと、結果も2行で表示される。
- Java は大文字小文字を区別するので、正確なつづりで書く必要がある。

**コード文法の分解**

```java
System.out.println("Hello");
```

| 部分 | 意味 |
|---|---|
| `System.out` | 画面へ出力するときに使う基本の形式 |
| `println` | 内容を出力した後、改行する。 |
| `"Hello"` | 画面に出力する文字 |
| `( )` | 出力する内容を書く位置 |
| `;` | 出力文の終わり |

**問題とは別の例**

```java
System.out.println("Java");
System.out.println("Beginner");
System.out.println("Lesson 01");
```

**実行の流れと結果**

- 1つ目の println が `Java` を出力して改行する。
- 2つ目の println が `Beginner` を出力して改行する。
- 3つ目の println が `Lesson 01` を出力する。

```
Java
Beginner
Lesson 01
```

**よくあるミス**

```java
System.out.println(Hello);     // 二重引用符がない
system.out.println("Hello");   // System の S が小文字
System.out.Println("Hello");   // println の p が大文字
System.out.println("Hello")    // セミコロンがない
```

文字を出力するときは、次の形を正確に守らなければならない。

```java
System.out.println("出力する文字");
```

### Part 3. print() と println() の違い

**概念説明**

- `System.out.print()` も括弧内の内容を画面に出力する。
- しかし `print` は出力した後に改行しない。
- 次の出力内容は同じ行に続けて表示される。
- 逆に `println` は出力後に次の行へ移動する。
- 2つの出力文を組み合わせると、同じ行への出力と改行を調整できる。

**コード文法の分解**

```java
System.out.print("Java");
System.out.println(" Start");
System.out.print("Done");
```

- 1つ目の print は `Java` を出力して同じ行にとどまる。
- 2つ目の println は ` Start` を続けて出力する。
- println が実行されたので、次の出力位置が下の行へ移動する。
- 3つ目の print は次の行に `Done` を出力する。

**実行結果**

```
Java Start
Done
```

**問題とは別の例**

```java
System.out.print("A");
System.out.print("B");
System.out.println("C");
System.out.println("D");
```

**実行の流れと結果**

- `A` を出力して同じ行にとどまる。
- `B` を同じ行に続けて出力する。
- `C` を続けて出力して改行する。
- 次の行に `D` を出力する。

```
ABC
D
```

**よくあるミス**

- `print` も自動で改行すると思ってしまう。
- 各出力文の間に自動で空白が入ると思ってしまう。
- コードで行を変えると出力結果も改行されると思ってしまう。
- `print` と `println` のつづりを混同する。

次の2つのコードは結果が違う。

```java
System.out.print("A");
System.out.print("B");
```

```
AB
```

```java
System.out.println("A");
System.out.println("B");
```

```
A
B
```

### Part 4. コメント

**概念説明**

- コメントはコードに説明を残すときに使う。
- コメントとして書かれた内容はプログラムが実行しない。
- `//` の後ろの内容は、その行の終わりまでコメントになる。
- `/*` と `*/` の間の内容は、複数行にわたってコメントになる。
- コメントはコードの目的や注意事項を説明するときに使う。
- 実行すべきコードをコメントにしてしまわないよう注意する。

**コード文法の分解**

```java
// 1行コメント
```

`//` の後ろから、現在の行が終わる部分までコメントとして扱われる。

```java
/*
複数行を
書けるコメント
*/
```

`/*` から `*/` までのすべての内容がコメントとして扱われる。

**問題とは別の例**

```java
public class Main {
    public static void main(String[] args) {
        // 学習開始メッセージを出力する。
        System.out.println("学習開始");

        /*
        次の出力文はコメントの中にあるので
        実行されない。
        System.out.println("出力されない");
        */
    }
}
```

**実行の流れと結果**

- 1行コメントは実行しない。
- `学習開始` を出力する。
- 複数行コメントの中の出力文は実行しない。
- プログラムが終了する。

```
学習開始
```

**よくあるミス**

```java
/ 1行コメント          // スラッシュが1つだけ

/*
複数行コメント          // 閉じる */ がない
```

- 1行コメントをスラッシュ `/` 1つだけで書く。
- 複数行コメントの最後の `*/` を書き忘れる。
- 実行すべきコードの前に、うっかり `//` を付ける。
- コメントの中の出力文も実行されると思ってしまう。
