## 学習目標

この課を学習した後、次の作業ができるようにする。

- 算術演算子で値を計算する。
- 代入・増減演算子で変数の値を変更する。
- 比較・論理演算の結果を求める。
- 演算子の優先順位を理解する。
- 自動型変換と強制型変換を区別する。

## 授業内容

### Part 1. 算術・代入・増減演算子

**概念説明**

- 算術演算子は数値を計算するときに使う。
- `+`、`-`、`*`、`/` は四則演算で、`%` は余りを求める。
- 整数どうしで割ると小数点以下は切り捨てられる。
- `+=`、`-=`、`*=`、`/=` は計算した結果を同じ変数に再び保存する。
- `++` と `--` は変数の値を1ずつ増やしたり減らしたりする。

**コード文法**

| 演算子 | 意味 | 例 |
|---|---|---|
| `+` | 足し算 | `10 + 3` |
| `-` | 引き算 | `10 - 3` |
| `*` | 掛け算 | `10 * 3` |
| `/` | 割り算 | `10 / 3` |
| `%` | 余り | `10 % 3` |
| `+=` | 足して保存 | `number += 3` |
| `++` | 1増やす | `number++` |
| `--` | 1減らす | `number--` |

**例**

```java
int number = 10;

number += 5;
number++;
number--;

System.out.println(number);
System.out.println(10 / 3);
System.out.println(10 % 3);
```

**実行結果**

```
15
3
1
```

**よくあるミス**

```java
double result = 5 / 2;
```

整数どうしを先に計算するため、結果は2.5ではなく2.0になる。

また、増減演算子を他の代入文に使うと、位置によって結果が変わる。

```java
int number = 5;
int result = number++;
```

`result` には5、`number` には6が保存される。

### Part 2. 比較・論理演算子

**概念説明**

- 比較演算子は2つの値を比較してtrueまたはfalseを作る。
- `==` は2つの値が等しいか、`!=` は異なるかを比較する。
- `>`、`<`、`>=`、`<=` は値の大小を比較する。
- `&&` は両方の条件がすべて真のとき真になる。
- `||` は1つ以上の条件が真のとき真になる。
- `!` はtrueとfalseを反対に変える。

**コード文法**

| 演算子 | 意味 |
|---|---|
| `==` | 等しい |
| `!=` | 等しくない |
| `>`, `<` | より大きい、より小さい |
| `>=`, `<=` | 以上、以下 |
| `&&` | 両方とも真 |
| `\|\|` | 1つ以上真 |
| `!` | 論理値の反転 |

**例**

```java
int score = 80;
boolean submitted = true;

boolean passed = score >= 60;
boolean completed = passed && submitted;
boolean excellent = score >= 90 || completed;

System.out.println(passed);
System.out.println(completed);
System.out.println(excellent);
```

**実行結果**

```
true
true
true
```

**よくあるミス**

```java
score = 80;                  // 値を保存 (代入)
boolean same = score == 80;  // 値が等しいか比較 (結果は boolean)
```

`=` は代入、`==` は比較である。`score == 80;` のように比較式だけを単独で書くと文にならずコンパイルエラーになる。

### Part 3. 演算子の優先順位

**概念説明**

- 1つの文に複数の演算子があると、決められた優先順位に従って計算する。
- 掛け算・割り算・余りは足し算・引き算より先に実行される。
- 比較演算は算術計算が終わった後に実行される。
- 括弧を使うと括弧の中の計算を先に実行できる。
- 計算順序が分かりにくいときは、括弧で明確に表すのがよい。

**例**

```java
int first = 2 + 3 * 4;
int second = (2 + 3) * 4;

System.out.println(first);
System.out.println(second);
```

**実行の流れと結果**

```
2 + 3 * 4   → 2 + 12 → 14
(2 + 3) * 4 → 5 * 4  → 20
```

```
14
20
```

**よくあるミス**

- すべての計算が必ず左から実行されると考えてはいけない。
- 複雑な式では優先順位を暗記するより括弧を使うほうが安全である。

### Part 4. 自動型変換と強制型変換

**概念説明**

- 型変換とは値を別の型に変えることである。
- 範囲の小さい数値型を範囲の大きい数値型に保存すると自動的に変換される。
- 範囲の大きい数値型を小さい範囲に変えるときは `(型名)` を書く。
- これを強制型変換という。
- 実数を整数に変換すると小数点以下は切り捨てられる。
- 強制型変換する値が型の範囲を超えると、元の値が保たれない場合がある。

**自動型変換の方向**

小さい型の値をより大きい型に保存すると自動的に変換され、これを**拡大プリミティブ変換**という。

```
byte → short → int → long → float → double
char → int → long → float → double
```

- `char` も `int` 以上の整数・実数型へ自動変換される。
- `long → float`、`long → double` のように整数から実数へ変換するときは自動変換されるが、値が大きいと精度が失われることがある。
- 「小さい範囲から大きい範囲へ」は理解を助ける表現であり、正確な名称は拡大プリミティブ変換である。

**例**

```java
int count = 10;
double first = count;

double price = 3.8;
int second = (int) price;

double division = (double) 5 / 2;

System.out.println(first);
System.out.println(second);
System.out.println(division);
```

**実行の流れと結果**

1. `count` は自動的にdoubleに変換される。
2. 3.8をintに変換すると小数点以下が切り捨てられる。
3. 5を先にdoubleに変換するため、実数の割り算が実行される。

```
10.0
3
2.5
```

**よくあるミス**

```java
double first = 5 / 2;            // 2.0
double second = (double) 5 / 2;  // 2.5
double third = (double) (5 / 2); // 2.0
```

型変換を計算前に行うか、計算後に行うかによって結果が変わる。

## まとめ

```java
int result = 10 + 3;
int remainder = 10 % 3;

int number = 5;
number += 2;
number++;

boolean passed = number >= 5 && number <= 10;

double division = (double) 5 / 2;
int integer = (int) 3.8;
```

- 整数の割り算は小数点以下を切り捨てる。
- 比較演算の結果はbooleanである。
- `=` は代入、`==` は比較である。
- 自動型変換（拡大プリミティブ変換）はより大きい型に保存するときに発生する。
- 強制型変換は `(型名)` で書く。
