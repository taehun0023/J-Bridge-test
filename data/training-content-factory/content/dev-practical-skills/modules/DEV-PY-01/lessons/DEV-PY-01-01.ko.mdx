## 1) 학습 목표

- Python 스크립트의 기본 구성(모듈 임포트, 함수 정의, 실행 진입점)을 설명할 수 있다.
- 들여쓰기가 코드 블록을 결정하는 방식을 설명할 수 있다.
- `if __name__ == "__main__"` 패턴의 목적을 설명할 수 있다.
- 기본 데이터 타입(str, int, float, list, dict, tuple)의 특성을 구분할 수 있다.

## 2) 업무 맥락

Python은 자동화 스크립트, 데이터 처리, API 서버 등 다양한 용도로 사용된다. 실무에서 동료가 작성한 Python 스크립트를 읽을 때, 들여쓰기 구조를 잘못 읽으면 실행 흐름을 완전히 오해할 수 있다. 중괄호 없이 들여쓰기만으로 블록을 구분하는 것은 Python의 가장 큰 특징이자 처음 접할 때 가장 혼란스러운 부분이다.

## 3) 핵심 설명

Python 스크립트는 위에서 아래로 순서대로 실행된다. 함수와 클래스 정의는 "등록"만 되고, 호출될 때 실행된다.

**들여쓰기 규칙**: Python은 들여쓰기로 코드 블록을 결정한다. 같은 수준의 들여쓰기를 가진 연속된 줄은 같은 블록에 속한다. 들여쓰기가 맞지 않으면 `IndentationError`가 발생한다.

**`if __name__ == "__main__"` 패턴**: 이 조건은 "이 파일이 직접 실행될 때만 아래 코드를 실행하라"는 의미다. 다른 파일에서 `import`할 때는 실행되지 않는다. 이 패턴을 사용하면 같은 파일을 라이브러리로도, 독립 스크립트로도 사용할 수 있다.

**기본 데이터 타입**:
- `str`: 불변(immutable) 문자열. `"hello"[0]`은 가능하지만 `"hello"[0] = "H"`는 불가능하다.
- `list`: 가변(mutable) 순서 있는 컬렉션. `append`, `pop` 등으로 수정 가능하다.
- `dict`: 키-값 쌍의 컬렉션. 키는 불변 타입만 가능하다.
- `tuple`: 불변 순서 있는 컬렉션. 한 번 생성하면 수정할 수 없다.

가변과 불변의 차이는 함수에 인자를 전달할 때 중요해진다. 가변 객체를 함수에 전달하면 함수 안에서의 변경이 원본에도 반영된다.

## 4) 실무 해석 시나리오

### 시나리오 A
```python
import os

def get_config_path():
    env = os.getenv("APP_ENV", "development")
    return f"/etc/app/{env}/config.yaml"

if __name__ == "__main__":
    path = get_config_path()
    print(f"Config path: {path}")
```
- 읽기 포인트:
  - `os` 모듈을 사용하여 환경 변수에 접근한다.
  - `APP_ENV`가 설정되지 않으면 기본값 `"development"`를 사용한다.
  - 이 파일을 직접 실행하면 경로를 출력하지만, 다른 파일에서 import하면 출력하지 않는다.

### 시나리오 B
```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("a"))  # ["a"]
print(add_item("b"))  # ["a", "b"] — 예상과 다를 수 있다
```
- 해석:
  - 기본 인자로 가변 객체(`[]`)를 사용하면 함수 호출 간에 같은 객체가 공유된다.
  - 두 번째 호출에서 `items`는 빈 리스트가 아니라 이전 호출에서 수정된 리스트다.
  - 이것은 Python의 대표적인 함정으로, 기본 인자에는 `None`을 사용하고 함수 내부에서 새 리스트를 만드는 것이 안전하다.

## 5) 자주 하는 실수

1. 들여쓰기에 탭과 스페이스를 혼용한다.
Python 3에서는 탭과 스페이스 혼용 시 `TabError`가 발생한다. 프로젝트 내에서 하나로 통일해야 한다.

2. 가변 객체를 함수 기본 인자로 사용한다.
리스트나 딕셔너리를 기본 인자로 사용하면 호출 간에 공유되어 예상치 못한 동작이 발생한다.

3. `if __name__ == "__main__"` 없이 최상위에 실행 코드를 작성한다.
이 경우 다른 모듈에서 import할 때 의도하지 않은 코드가 실행된다.

4. 문자열이 불변이라는 것을 모르고 수정을 시도한다.
문자열은 새로운 문자열을 만들어야 한다. `replace`나 f-string을 사용한다.
