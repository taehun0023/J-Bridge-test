## 1) 学習目標

- Pythonスクリプトの基本構成（モジュールインポート、関数定義、実行エントリーポイント）を説明できる。
- インデントがコードブロックを決定する仕組みを説明できる。
- `if __name__ == "__main__"`パターンの目的を説明できる。
- 基本データ型（str、int、float、list、dict、tuple）の特性を区別できる。

## 2) 業務コンテキスト

Pythonは自動化スクリプト、データ処理、APIサーバーなど多様な用途で使用される。実務で同僚が作成したPythonスクリプトを読む際、インデント構造を誤って読むと実行フローを完全に誤解する可能性がある。波括弧なしにインデントだけでブロックを区別するのはPythonの最大の特徴であり、初めて触れる際に最も混乱しやすい部分である。

## 3) 要点解説

Pythonスクリプトは上から下へ順番に実行される。関数やクラスの定義は「登録」されるだけで、呼び出された時に実行される。

**インデントルール**：Pythonはインデントでコードブロックを決定する。同じレベルのインデントを持つ連続した行は同じブロックに属する。インデントが合っていなければ`IndentationError`が発生する。

**`if __name__ == "__main__"`パターン**：この条件は「このファイルが直接実行された時のみ以下のコードを実行する」という意味である。他のファイルから`import`する際には実行されない。このパターンを使用すると、同じファイルをライブラリとしても独立スクリプトとしても使用できる。

**基本データ型**：
- `str`：不変（immutable）文字列。`"hello"[0]`は可能だが`"hello"[0] = "H"`は不可能である。
- `list`：可変（mutable）で順序ありのコレクション。`append`、`pop`などで変更可能である。
- `dict`：キーと値のペアのコレクション。キーには不変型のみ使用可能である。
- `tuple`：不変で順序ありのコレクション。一度生成すると変更できない。

可変と不変の違いは、関数に引数を渡す際に重要になる。可変オブジェクトを関数に渡すと、関数内での変更が元のオブジェクトにも反映される。

## 4) 実務解釈シナリオ

### シナリオ A
```python
import os

def get_config_path():
    env = os.getenv("APP_ENV", "development")
    return f"/etc/app/{env}/config.yaml"

if __name__ == "__main__":
    path = get_config_path()
    print(f"Config path: {path}")
```
- 読み取りポイント：
  - `os`モジュールを使用して環境変数にアクセスしている。
  - `APP_ENV`が設定されていなければデフォルト値`"development"`が使用される。
  - このファイルを直接実行するとパスが出力されるが、他のファイルからimportすると出力されない。

### シナリオ B
```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("a"))  # ["a"]
print(add_item("b"))  # ["a", "b"] — 予想と異なる可能性がある
```
- 解釈：
  - デフォルト引数に可変オブジェクト（`[]`）を使用すると、関数呼び出し間で同じオブジェクトが共有される。
  - 2回目の呼び出しで`items`は空のリストではなく、前回の呼び出しで変更されたリストである。
  - これはPythonの代表的な落とし穴であり、デフォルト引数には`None`を使用し、関数内部で新しいリストを作成するのが安全である。

## 5) よくあるミス

1. インデントにタブとスペースを混在させる。
Python 3ではタブとスペースの混在時に`TabError`が発生する。プロジェクト内でどちらかに統一する必要がある。

2. 可変オブジェクトを関数のデフォルト引数に使用する。
リストやディクショナリをデフォルト引数に使用すると、呼び出し間で共有され予期しない動作が発生する。

3. `if __name__ == "__main__"`なしでトップレベルに実行コードを記述する。
この場合、他のモジュールからimportする際に意図しないコードが実行される。

4. 文字列が不変であることを知らずに変更を試みる。
文字列は新しい文字列を作成する必要がある。`replace`やf-stringを使用する。
