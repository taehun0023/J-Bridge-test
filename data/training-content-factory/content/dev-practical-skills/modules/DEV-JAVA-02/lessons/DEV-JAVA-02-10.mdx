## 学習目標

このパートを学習した後、次の作業ができるようになる必要があります。

- オブジェクトを格納する配列を宣言・生成する。
- オブジェクト配列の各要素が参照値を保存することを理解する。
- 繰り返し文でオブジェクト配列を巡回する。
- オブジェクト配列で合計と検索を行う。
- あるオブジェクトが別のオブジェクトを使って作業する協力関係を実装する。

## 授業内容

### Part 1. オブジェクト配列が必要な理由

複数の学生をそれぞれ別の変数に保存すると管理が難しくなる。

```java
Student student1 = new Student("Minsu", 80);
Student student2 = new Student("Jisu", 90);
Student student3 = new Student("Seojun", 70);
```

オブジェクト配列を使うと、同じ種類のオブジェクトを一つの配列でまとめて管理できる。

```java
Student[] students = new Student[3];
```

このコードはStudentオブジェクトを3つ作ったわけではない。Studentオブジェクトの参照値を保存する空間を3つ作る。

最初はすべての要素がnullである。

### Part 2. オブジェクト配列にオブジェクトを格納する

```java
students[0] = new Student("Minsu", 80);
students[1] = new Student("Jisu", 90);
students[2] = new Student("Seojun", 70);
```

各要素を通じてオブジェクトのメソッドを呼び出せる。

```java
System.out.println(students[1].getName());
```

**実行結果**

```text
Jisu
```

### Part 3. 宣言と同時にオブジェクトを格納する

```java
Student[] students = {
    new Student("Minsu", 80),
    new Student("Jisu", 90),
    new Student("Seojun", 70)
};
```

配列にはオブジェクトそのものではなく、各オブジェクトを指す参照値が保存される。

### Part 4. オブジェクト配列を巡回する

```java
for (int i = 0; i < students.length; i++) {
    System.out.println(students[i].getName());
}
```

拡張for文を使ってもよい。

```java
for (Student student : students) {
    System.out.println(student.getName());
}
```

要素がnullである可能性がある場合は、まず検査する。

```java
for (Student student : students) {
    if (student != null) {
        System.out.println(student.getName());
    }
}
```

### Part 5. オブジェクト配列の合計を求める

```java
int total = 0;

for (Student student : students) {
    total += student.getScore();
}

System.out.println(total);
```

**実行結果**

```text
240
```

オブジェクト配列でも一般の配列と同様に、合計・平均・最大値・検索の作業を行える。違いは、要素のメソッドを通じて値を利用する点である。

### Part 6. オブジェクト間の協力が必要な理由

注文金額を計算するには、注文オブジェクトが商品の価格を知る必要がある。

```java
class Product {
    private String name;
    private int price;

    public Product(String name, int price) {
        this.name = name;
        this.price = price;
    }

    public int getPrice() {
        return price;
    }
}
```

OrderオブジェクトはProductオブジェクトをフィールドとして持つことができる。

```java
class Order {
    private Product product;
    private int quantity;

    public Order(Product product, int quantity) {
        this.product = product;
        this.quantity = quantity;
    }

    public int getTotalPrice() {
        return product.getPrice() * quantity;
    }
}
```

```java
Product product = new Product("キーボード", 30000);
Order order = new Order(product, 2);

System.out.println(order.getTotalPrice());
```

**実行結果**

```text
60000
```

Orderはすべての商品情報を自分で複製せず、Productオブジェクトに価格を問い合わせる。このようにオブジェクトが他のオブジェクトの機能を使って作業することをオブジェクト間の協力という。

### 総合例

```java
class Student {
    private String name;
    private int score;

    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    public String getName() {
        return name;
    }

    public int getScore() {
        return score;
    }
}

class Classroom {
    private Student[] students;

    public Classroom(Student[] students) {
        this.students = students;
    }

    public int getTotalScore() {
        int total = 0;

        for (Student student : students) {
            if (student != null) {
                total += student.getScore();
            }
        }

        return total;
    }
}

public class Main {
    public static void main(String[] args) {
        Student[] students = {
            new Student("Minsu", 80),
            new Student("Jisu", 90),
            new Student("Seojun", 70)
        };

        Classroom classroom = new Classroom(students);

        System.out.println(classroom.getTotalScore());
    }
}
```

**実行結果**

```text
240
```
