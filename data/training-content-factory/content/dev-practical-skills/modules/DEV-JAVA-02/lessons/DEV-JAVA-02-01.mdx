## 学習目標

このパートを学習した後、次の作業ができるようにする。

- クラスとオブジェクトの関係を説明する。
- オブジェクトを表現するクラスを宣言する。
- new を使ってオブジェクトを生成する。
- ドット演算子でオブジェクトのデータにアクセスする。
- 1つのクラスで複数のオブジェクトを作る。

## 授業内容

### Part 1. クラスとオブジェクト

学生1人の情報を複数の変数で表現できる。

```java
String name = "Minsu";
int score = 85;
```

学生が複数人になると、学生ごとに変数を別々に作らなければならない。

```java
String name1 = "Minsu";
int score1 = 85;

String name2 = "Jisu";
int score2 = 92;
```

クラスを使うと、名前や点数のように互いに関連するデータを1つのオブジェクトにまとめられる。

```java
class Student {
    String name;
    int score;
}
```

クラスはオブジェクトがどんなデータを持つかを定義した設計図である。上の Student クラスは、学生オブジェクトが名前と点数を持てるように定義している。

クラスを宣言しただけでは、学生オブジェクトは作られない。

### Part 2. オブジェクトの生成

クラスから実際のオブジェクトを作るときは new を使う。

```java
Student student = new Student();
```

- `Student`: オブジェクトを作るときに使うクラス
- `student`: 生成したオブジェクトを使う変数
- `new Student()`: 新しい Student オブジェクトの生成

オブジェクトを生成する基本形式は次の通りである。

```java
クラス名 オブジェクト変数 = new クラス名();
```

クラスから生成されたオブジェクトを、そのクラスのインスタンスという。

```java
Student student = new Student();
```

上で生成したオブジェクトは Student クラスのインスタンスである。`Student()` が動作する詳しい過程はコンストラクタのパートで学習する。

**よくあるミス**

オブジェクトを生成するとき new を忘れてはいけない。

```java
Student student = Student(); // コンパイルエラー
```

正しいコードは次の通りである。

```java
Student student = new Student();
```

Java は大文字小文字を区別するので、クラス名も正確に書く必要がある。

```java
Student student = new student(); // コンパイルエラー
```

### Part 3. オブジェクトのデータの使用

オブジェクトが持つデータには、ドット演算子 `.` でアクセスする。

```java
Student student = new Student();

student.name = "Minsu";
student.score = 85;
```

オブジェクトのデータを読み取るときも、ドット演算子を使う。

```java
System.out.println(student.name);
System.out.println(student.score);
```

**実行結果**

```text
Minsu
85
```

基本形式は次の通りである。

```java
オブジェクト変数.データ名 = 値;
System.out.println(オブジェクト変数.データ名);
```

オブジェクト内部に宣言された変数の正確な名称と特徴は、次のパートで学習する。

**よくあるミス**

ドット演算子を忘れると、オブジェクトのデータを使うことができない。

```java
student name = "Minsu"; // コンパイルエラー
student.name = "Minsu";
```

クラスに宣言されていないデータも使うことができない。

```java
class Student {
    String name;
    int score;
}

Student student = new Student();

student.age = 20; // age が宣言されていないのでコンパイルエラー
```

### Part 4. 1つのクラスで複数のオブジェクトを作る

1つのクラスで複数のオブジェクトを作ることができる。

```java
Student student1 = new Student();
Student student2 = new Student();
```

2つのオブジェクトに互いに異なる値を保存できる。

```java
student1.name = "Minsu";
student1.score = 85;

student2.name = "Jisu";
student2.score = 92;
```

```java
System.out.println(student1.name);
System.out.println(student1.score);

System.out.println(student2.name);
System.out.println(student2.score);
```

**実行結果**

```text
Minsu
85
Jisu
92
```

student1 と student2 は同じ Student クラスで作ったが、別々のオブジェクトである。クラスは一度宣言し、そのクラスを利用して必要な数だけオブジェクトを作ることができる。

### 総合例

```java
class Product {
    String name;
    int price;
}

public class Main {
    public static void main(String[] args) {
        Product product1 = new Product();
        Product product2 = new Product();

        product1.name = "キーボード";
        product1.price = 35000;

        product2.name = "マウス";
        product2.price = 20000;

        System.out.println(product1.name + ": " + product1.price + "円");
        System.out.println(product2.name + ": " + product2.price + "円");
    }
}
```

**実行結果**

```text
キーボード: 35000円
マウス: 20000円
```

Product クラスは商品オブジェクトが名前と価格を持てるように定義している。product1 と product2 は同じクラスで生成された別々のオブジェクトである。
