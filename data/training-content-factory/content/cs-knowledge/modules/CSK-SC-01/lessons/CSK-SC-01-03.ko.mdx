## 1) 학습 목표
- XSS, SQL 인젝션, CSRF의 구조와 공격 방법을 설명할 수 있다
- 각 취약점에 대한 기본적인 방어 대책을 이해한다
- 다층 방어(Defense in Depth)의 개념을 실무에 적용할 수 있다

## 2) 왜 중요한가
웹 애플리케이션의 취약점은 개인정보 유출이나 서비스 중단으로 직결되는 중대한 위험이다. OWASP Top 10에 항상 포함되는 XSS와 인젝션 공격은 개발자가 올바른 방어 대책을 모르면 쉽게 발생한다. 보안이 고려된 코드를 작성하는 것은 품질 높은 소프트웨어를 제공하는 데 필수적인 역량이다.

## 3) 핵심 설명
- **XSS(Cross-Site Scripting)**: 공격자가 악성 스크립트를 웹 페이지에 삽입하여 다른 사용자의 브라우저에서 실행시키는 공격이다. 저장형(Stored)은 DB에 저장된 스크립트가 모든 사용자에게 영향을 미치고, 반사형(Reflected)은 URL 파라미터를 통해 즉시 실행된다
- **SQL 인젝션**: 사용자 입력이 SQL문에 그대로 포함되어 공격자가 임의의 SQL을 실행할 수 있는 취약점이다. DB 내 전체 데이터 유출이나 데이터 변조가 가능해진다
- **CSRF(Cross-Site Request Forgery)**: 로그인 중인 사용자에게 의도하지 않은 요청을 보내게 하는 공격이다. 피해자의 세션을 이용하여 부정 조작(송금, 설정 변경 등)을 수행한다

## 4) 작동 방식 또는 판단 흐름
1. **XSS 공격과 방어**: 공격자가 게시판 등에 스크립트를 게시 → 다른 사용자가 페이지를 열람 → 스크립트가 실행되어 쿠키 탈취나 피싱이 발생한다. 방어 대책으로 출력 시 이스케이프 처리, Content Security Policy(CSP) 설정, 입력값 새니타이징을 수행한다
2. **SQL 인젝션 공격과 방어**: 공격자가 폼에 `' OR 1=1 --`과 같은 문자열을 입력 → SQL문이 변조되어 인증 우회나 데이터 유출이 발생한다. 방어 대책으로 프리페어드 스테이트먼트(파라미터화 쿼리)를 반드시 사용하고 동적 SQL 구성을 피한다
3. **CSRF 공격과 방어**: 공격자가 함정 사이트에 자동 전송 폼을 설치 → 로그인 중인 사용자가 접근 → 정상 사이트에 부정 요청이 전송된다. 방어 대책으로 CSRF 토큰 삽입, SameSite 쿠키 속성 설정, Referer 헤더 검증을 수행한다

## 5) 비슷한 개념과의 비교
- **XSS vs CSRF**: XSS는 피해자의 브라우저에서 스크립트를 실행하는 공격이고, CSRF는 피해자의 인증 정보를 이용하여 요청을 위조하는 공격이다. XSS는 클라이언트 측, CSRF는 서버 측 처리를 악용한다는 점이 다르다
- **입력 유효성 검사 vs 출력 이스케이프**: 입력 유효성 검사는 부적절한 데이터의 유입을 막고, 출력 이스케이프는 표시 시 실행을 방지한다. 둘을 조합하여 다층 방어를 실현한다

## 6) 자주 하는 오해
- "프론트엔드에서 유효성 검사를 하면 안전하다" → 프론트엔드 검증은 브라우저 개발자 도구로 쉽게 우회할 수 있다. 서버 측 검증이 필수이다
- "우리 사이트는 소규모라서 공격당하지 않는다" → 자동화된 공격 도구는 사이트 규모와 관계없이 무차별적으로 스캔한다. 규모와 무관하게 대책이 필요하다
- "HTTPS를 사용하면 XSS나 SQL 인젝션을 방지할 수 있다" → HTTPS는 통신 암호화이며 애플리케이션 계층의 취약점과는 무관하다. 각각 별도의 대책이 필요하다

## 7) 확인 질문
1. 저장형 XSS와 반사형 XSS의 차이를 공격 경로 관점에서 설명하세요
2. 프리페어드 스테이트먼트가 SQL 인젝션을 방지할 수 있는 이유는 무엇인가요
3. CSRF 토큰은 어떤 원리로 부정 요청을 차단하나요
4. 다층 방어(Defense in Depth)의 개념을 웹 취약점 대책에 적용하여 설명하세요

## 8) 문항 추출 메모
- XSS, SQL 인젝션, CSRF의 공격 방법과 방어 대책의 대응 관계는 객관식 문제에 적합하다
- 공격 코드 예시(`<script>alert(1)</script>`, `' OR 1=1 --`)를 보여주고 취약점을 식별하는 시나리오 문제가 효과적이다
- 방어 대책의 우선순위나 조합(다층 방어)에 관한 문제로 이해의 깊이를 측정할 수 있다
